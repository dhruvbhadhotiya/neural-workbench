How to use this module

offline · exact and illustrative labs · read in order

Run the flagship lab

Lesson 1 trains two MLPs directly in your browser with a time-sliced loop. Press Run and watch the generated histogram, the discriminator's decision curve and both losses.

Read the badge first

Exact math means a number is computed from the data on screen. Illustrative means the trace is schematic and says so. M3 has both kinds.

Same notation throughout

\(\eta\) is the learning rate, \(\lambda\) a loss weight, images are NCHW, and \(z\) is latent noise. The worked examples use small integers you can check by hand.
