DCGAN and conditional GANs

— · Lesson 3 of 4 · Exact math labs

Replace flat vectors with convolutions, compute every shape and parameter count, then tell the generator which class (or attribute) to draw.

Objectives

  • Compute transposed-convolution output sizes and trace a 100-vector to a 3×64×64 image.
  • Count the parameters of the DCGAN generator and discriminator with shown arithmetic.
  • State the DCGAN design rules and explain what batch norm, LeakyReLU and spectral norm change.
  • Write the conditional GAN objective and describe how conditioning enters both networks.

You know this from ML → here it becomes

A CNN encoder turns an image into a small feature map. The DCGAN generator is the mirror: it starts from a small feature map and uses transposed convolutions to grow it back into an image. Conditioning then adds a label \(y\) to both sides of the game.

Intuition: growing an image from noise

A multilayer perceptron can output \(3\cdot64\cdot64=12{,}288\) numbers, but it ignores the spatial structure of an image. DCGAN uses strided convolutions in the discriminator and transposed convolutions in the generator, so each layer has a local receptive field and the number of channels changes in a regular pattern. The generator ends in \(\tanh\), matching images scaled to \([-1,1]\); there is no final BatchNorm on the output layer.

Toggle network and layers in the tracer. With all options on, the totals reproduce python tools/params.py dcgan_g dcgan_d: 3,577,667 generator parameters and 2,765,633 discriminator parameters. Turning batch norm off removes exactly \(2C\) parameters per normalised layer; LeakyReLU and spectral norm add none.

The math

1 · Transposed-convolution output size

\[ H'=(H-1)S-2P+D(K-1)+\text{output\_padding}+1 \]

\(H\) is the input height (width \(W\) is identical for square inputs), \(K\) the kernel size, \(S\) the stride, \(P\) the zero-padding passed to ConvTranspose2d, \(D\) the dilation, and output_padding an extra additive term used to resolve stride ambiguities. The standard DCGAN generator uses \(D=1\) and output_padding=0.

Worked examples.

\[ H=1,K=4,S=1,P=0:\quad (1-1)\cdot1-0+1\cdot(4-1)+0+1=0+3+1=4 \] \[ H=4,K=4,S=2,P=1:\quad (4-1)\cdot2-2+1\cdot(4-1)+0+1=6-2+3+1=8 \]

2 · The shape trace

\[ \mathbf{z}\in\mathbb{R}^{100} \;\longrightarrow\ (512,4,4)\ \longrightarrow\ (256,8,8)\ \longrightarrow\ (128,16,16) \ \longrightarrow\ (64,32,32)\ \longrightarrow\ (3,64,64) \]

These are single-sample shapes \((C,H,W)\); a minibatch of \(N\) images is \((N,C,H,W)\) in NCHW order. The first transposed convolution has \(K^2 C_{\text{in}}C_{\text{out}}+C_{\text{out}}=4^2\cdot100\cdot512+512=819{,}712\) parameters. The next has \(4^2\cdot512\cdot256+256=2{,}097{,}408\).

3 · The DCGAN rules

  • Use strided convolutions in \(D\), transposed convolutions in \(G\).
  • BatchNorm in both networks, except the output layer of \(G\) and the input layer of \(D\).
  • ReLU in \(G\) (all layers but the output); LeakyReLU in \(D\).
  • \(\tanh\) on \(G\)'s output and images scaled to \([-1,1]\).

Spectral normalisation is a later refinement: replace \(\mathbf{W}\) by \(\mathbf{W}_{\mathrm{SN}}=\mathbf{W}/\sigma(\mathbf{W})\), where \(\sigma\) is the largest singular value. Worked example. If \(\sigma(\mathbf{W})=4\), every entry is divided by 4; a weight 0.8 becomes 0.2 and the layer's Lipschitz constant is bounded by 1. It adds no parameters.

4 · Conditioning on a label

\[ \min_G\max_D V(D,G\mid y)= \mathbb{E}_{\mathbf{x}\sim p_{\text{data}}}\log D(\mathbf{x}\mid y) +\mathbb{E}_{\mathbf{z}}\log\bigl(1-D(G(\mathbf{z}\mid y)\mid y)\bigr) \]

Here \(y\) is a class index or attribute vector. It is given to both networks: \(G\) sees \([\mathbf{z};y]\) (or an embedding of \(y\)) and \(D\) sees the image together with \(y\). This turns an unconditional sampler into \(N_{\text{classes}}\) controlled samplers.

Worked example. With a correct label, suppose \(D(\mathbf{x}\mid y)=0.900\) for a real image; BCE contributes \(-\log 0.900=0.10536\). With a wrong label the discriminator outputs \(D(\mathbf{x}\mid y')=0.198\), giving \(-\log 0.198=1.61659\). The mean over these two samples is \((0.10536+1.61659)/2=0.86098\): the discriminator is rewarded for detecting the mismatch.

A projection discriminator uses \(f(\mathbf{x},y)=a(y)+\mathbf{v}(\mathbf{x})^\top\mathbf{w}(y)\) instead of concatenating \(y\). Worked example. With \(a(y)=0.5\), \(\mathbf{v}=(1,-1)\) and \(\mathbf{w}=(1.2,0.2)\), the logit is \(0.5+1\cdot1.2+(-1)\cdot0.2=1.5\), so \(D=\sigma(1.5)=0.81757\).

Symbols used in this lesson

\(N\) batch size · \(C,H,W\) channels, height, width · \(K\) kernel size · \(S\) stride · \(P\) padding · \(D\) dilation (here 1) · \(\mathbf{z}\in\mathbb{R}^{100}\) latent vector · \(G,D\) generator and discriminator · \(y\) class label · \(\sigma\) singular value (in the spectral-norm paragraph) or sigmoid (where stated) · \(\mathbf{v},\mathbf{w}\) projection feature and class embedding · \(a(y)\) class bias.

Code

The PyTorch listing is fully self-contained: procedural blob images are generated with tensor arithmetic, then a DCGAN is trained for a few hundred steps. The commented lines show the standard MNIST/CIFAR swap for a real experiment. The Keras tab builds the same architecture (Keras uses NHWC internally; comments state the equivalent NCHW shapes used in prose). 

import torch
from torch import nn

torch.manual_seed(0)
device = "cpu"

# ---- procedural "blob" images, shape (N, 3, 64, 64) in [-1, 1] ----
yy, xx = torch.meshgrid(torch.linspace(-1, 1, 64), torch.linspace(-1, 1, 64), indexing="ij")
grid = torch.stack([xx, yy]).unsqueeze(0)          # (1, 2, 64, 64)

def make_blobs(n):
    cx, cy = torch.rand(n, 1, 1) * 1.2 - 0.6, torch.rand(n, 1, 1) * 1.2 - 0.6
    r = torch.rand(n, 1, 1) * 0.35 + 0.18
    d2 = (grid[0, 0] - cx) ** 2 + (grid[0, 1] - cy) ** 2
    disk = (d2 < r ** 2).float() * 2 - 1          # (n, 64, 64)
    return disk.unsqueeze(1).repeat(1, 3, 1, 1)     # (N, C, H, W) = (n, 3, 64, 64)

real_data = make_blobs(256).to(device)

class Generator(nn.Module):
    def __init__(self, z=100):
        super().__init__()
        self.net = nn.Sequential(
            nn.ConvTranspose2d(z, 512, 4, 1, 0, bias=False),   # 1x1 -> 4x4
            nn.BatchNorm2d(512), nn.ReLU(True),
            nn.ConvTranspose2d(512, 256, 4, 2, 1, bias=False), # 4 -> 8
            nn.BatchNorm2d(256), nn.ReLU(True),
            nn.ConvTranspose2d(256, 128, 4, 2, 1, bias=False), # 8 -> 16
            nn.BatchNorm2d(128), nn.ReLU(True),
            nn.ConvTranspose2d(128, 64, 4, 2, 1, bias=False),  # 16 -> 32
            nn.BatchNorm2d(64), nn.ReLU(True),
            nn.ConvTranspose2d(64, 3, 4, 2, 1, bias=False),    # 32 -> 64
            nn.Tanh(),
        )
    def forward(self, z):
        return self.net(z.view(z.size(0), -1, 1, 1))  # (N,100) -> (N,3,64,64)

class Discriminator(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(3, 64, 4, 2, 1), nn.LeakyReLU(0.2, inplace=True),      # 64 -> 32
            nn.Conv2d(64, 128, 4, 2, 1, bias=False), nn.BatchNorm2d(128),
            nn.LeakyReLU(0.2, inplace=True),                                  # 32 -> 16
            nn.Conv2d(128, 256, 4, 2, 1, bias=False), nn.BatchNorm2d(256),
            nn.LeakyReLU(0.2, inplace=True),                                  # 16 -> 8
            nn.Conv2d(256, 512, 4, 2, 1, bias=False), nn.BatchNorm2d(512),
            nn.LeakyReLU(0.2, inplace=True),                                  # 8 -> 4
            nn.Conv2d(512, 1, 4, 1, 0), nn.Sigmoid(),                         # 4 -> 1
        )
    def forward(self, x):
        return self.net(x).view(-1)                       # (N,1,1,1) -> (N,)

G, D = Generator().to(device), Discriminator().to(device)
print("G params", sum(p.numel() for p in G.parameters()))  # bias=False variant: 963 fewer than tools/params.py
print("D params", sum(p.numel() for p in D.parameters()))  # see tools/params.py dcgan_d
print("fake shape", tuple(G(torch.randn(2, 100)).shape))   # (2, 3, 64, 64)

opt_g = torch.optim.Adam(G.parameters(), lr=2e-4, betas=(0.5, 0.999))
opt_d = torch.optim.Adam(D.parameters(), lr=2e-4, betas=(0.5, 0.999))
bce = nn.BCELoss()

for step in range(300):
    idx = torch.randint(0, len(real_data), (32,))
    real = real_data[idx]
    fake = G(torch.randn(32, 100, device=device))

    opt_d.zero_grad()
    loss_d = bce(D(real), torch.ones(32)) + bce(D(fake.detach()), torch.zeros(32))
    loss_d.backward(); opt_d.step()

    opt_g.zero_grad()
    loss_g = bce(D(G(torch.randn(32, 100, device=device))), torch.ones(32))
    loss_g.backward(); opt_g.step()
    if step % 50 == 0:
        print(step, round(loss_d.item(), 4), round(loss_g.item(), 4))

import tensorflow as tf

tf.random.set_seed(0)
L = tf.keras.layers

def generator(z_dim=100):
    # Keras convolutions use NHWC internally; the prose traces NCHW shapes.
    inp = L.Input(shape=(z_dim,))
    x = L.Reshape((1, 1, z_dim))(inp)                   # NCHW equivalent: (N,100,1,1)
    x = L.Conv2DTranspose(512, 4, strides=1, padding="valid", use_bias=False)(x)
    x = L.BatchNormalization()(x); x = L.ReLU()(x)     # 4x4, 512 channels
    x = L.Conv2DTranspose(256, 4, strides=2, padding="same", use_bias=False)(x)
    x = L.BatchNormalization()(x); x = L.ReLU()(x)     # 8x8
    x = L.Conv2DTranspose(128, 4, strides=2, padding="same", use_bias=False)(x)
    x = L.BatchNormalization()(x); x = L.ReLU()(x)     # 16x16
    x = L.Conv2DTranspose(64, 4, strides=2, padding="same", use_bias=False)(x)
    x = L.BatchNormalization()(x); x = L.ReLU()(x)     # 32x32
    out = L.Conv2DTranspose(3, 4, strides=2, padding="same", use_bias=False)(x)
    out = L.Activation("tanh")(out)                    # 64x64x3, values in [-1, 1]
    return tf.keras.Model(inp, out, name="generator")

def discriminator():
    inp = L.Input(shape=(64, 64, 3))
    x = L.Conv2D(64, 4, strides=2, padding="same")(inp)  # 32x32
    x = L.LeakyReLU(0.2)(x)
    for c in (128, 256, 512):
        x = L.Conv2D(c, 4, strides=2, padding="same", use_bias=False)(x)
        x = L.BatchNormalization()(x)
        x = L.LeakyReLU(0.2)(x)                          # 16, 8, 4
    out = L.Conv2D(1, 4, strides=1, padding="valid")(x)  # 1x1x1 logit
    return tf.keras.Model(inp, out, name="discriminator")

G, D = generator(), discriminator()
G.summary(); D.summary()
print("G params", G.count_params(), "D params", D.count_params())

Common mistakes

BatchNorm in D's input layer

Normalising the raw image destroys the scale information \(D\) needs to spot fakes. Use LeakyReLU on that first layer and start BatchNorm only at the second.

No \(\tanh\) on G's output

Real images are scaled to \([-1,1]\). A generator ending in ReLU or sigmoid produces pixels in the wrong range, so \(D\) can win on brightness alone.

Wrong kernel/stride pair

\(K=4,S=2,P=1\) exactly doubles the spatial size. With \(K=3,S=2,P=1\) you get an odd off-by-one size; use the output-size formula before guessing.

Inconsistent conditioning

Concatenating the label and adding a projection head are both valid, but \(G\) and \(D\) must agree on the same representation. Mixing them silently trains different tasks.

Debug this

A reader reports: “my DCGAN's discriminator reaches 100% accuracy immediately, and the generated images look like flat grey tiles.” The procedural real data is in \([-1,1]\).

Show the likely cause and the fix

The generator's output range does not match the data range. Most often the final nn.Tanh() was replaced by nn.Sigmoid() (output in \([0,1]\)), or the real images were left in \([0,255]\) or \([0,1]\) while \(G\) outputs \([-1,1]\). Make both sides use the same range: scale real images with transforms.Normalize([0.5], [0.5]) for one channel (or three 0.5 values for RGB) and keep nn.Tanh() at the end of \(G\).

Second check: verify the fake shape with G(torch.randn(2,100)).shape — it must be (2, 3, 64, 64) before it reaches \(D\).

Summary

1 · A DCGAN generator grows 100 noise numbers into a (3,64,64) image with four transposed convolutions and halves the channels each time.
2 · The exact parameter totals are 3,577,667 for G and 2,765,633 for D; batch norm contributes 2C per normalised layer.
3 · A conditional GAN gives the label y to both networks; projection discriminators replace concatenation with a dot-product score.

Cheat sheet — M3·03

  • Transposed conv: \(H'=(H-1)S-2P+D(K-1)+\text{output\_padding}+1\).
  • Shape trace: 100 → (512,4,4) → (256,8,8) → (128,16,16) → (64,32,32) → (3,64,64).
  • Conv params \(K^2C_{\text{in}}C_{\text{out}}+C_{\text{out}}\); BN params \(2C\). DCGAN: G 3.58M, D 2.77M.
  • DCGAN rules: strided/transposed convs, BN except G output and D input, ReLU/LeakyReLU, tanh output.
  • cGAN objective: \(\mathbb{E}\log D(x\mid y)+\mathbb{E}\log(1-D(G(z\mid y)\mid y))\).
  • Spectral norm: \(W_{\mathrm{SN}}=W/\sigma(W)\); projection: \(a(y)+v(x)^\top w(y)\).
