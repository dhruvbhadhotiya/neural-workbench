Saliency and Grad-CAM

— · Lesson 3 of 7 · Exact math labs

Feature importance for trees has an image analogue: which pixels changed the class score most? You can compute that map exactly, and also see exactly how easy it is to misread it.

Objectives

  • Compute a saliency map from gradients of a class score with respect to input pixels.
  • Distinguish absolute from signed saliency and explain SmoothGrad's averaging.
  • State the Grad-CAM formula and the role of gradient global average pooling.
  • List the sanity checks that separate real evidence from pretty noise.

You know this from ML → here it becomes

A tree model tells you a feature's importance by how much the split loss improves. For an image classifier the analogous question is "how much would this pixel's brightness have to change to move the class score?" Backpropagation answers it in one pass — with no perturb-and-retest loop per pixel.

Intuition: a first-order sensitivity map

Take the score \(y^c\) of class \(c\) — a logit, before softmax. A one-unit change in pixel \(x_{i,j}\) changes the score by roughly \(\partial y^c/\partial x_{i,j}\). That derivative is cheap because autograd already computes a gradient with respect to the input if we ask for it. Absolute saliency answers "how much"; signed saliency answers "in which direction": a positive derivative means brightening the pixel raises the score, a negative one means brightening lowers it.

The caveat is first-order: the derivative at the current image says nothing about large changes. Saliency can highlight a single noisy pixel that happens to have a large local slope. Grad-CAM trades pixel resolution for stability by asking which channels in a late convolution layer matter, then upsampling the channel-weighted map.

A heatmap is a derivative, not an explanation by itself. Trust it only after checking that it changes when the label changes and vanishes when the model's weights are randomised.

The math

1 · Input saliency

\[ S_{i,j} = \left|\frac{\partial y^c}{\partial x_{i,j}}\right|, \qquad S^{\text{signed}}_{i,j} = \frac{\partial y^c}{\partial x_{i,j}} \]

Here \(y^c\) is the \(c\)-th logit and \(x_{i,j}\) the input pixel at row \(i\), column \(j\). In NCHW notation the image is \(\mathsf{X}\in\mathbb{R}^{1\times C\times H\times W}\), and the gradient has the same shape.

Worked example on three pixels. Let \(y=2x_1-3x_2+0.5x_3+1\) with \(x=(0.2,0.7,0.4)\). The score is \(y=2(0.2)-3(0.7)+0.5(0.4)+1=0.4-2.1+0.2+1=-0.5\). The gradient is \((\partial y/\partial x_1,\partial y/\partial x_2,\partial y/\partial x_3)=(2,-3,0.5)\); absolute saliency is \((2,3,0.5)\), signed saliency is \((2,-3,0.5)\). Pixel 2 is the most important by magnitude even though it pushes the score down.

2 · Grad-CAM recap

\[ \alpha_k^c = \frac{1}{HW}\sum_{i=1}^{H}\sum_{j=1}^{W} \frac{\partial y^c}{\partial A^k_{i,j}}\,, \qquad L^c_{i,j} = \mathrm{ReLU}\!\left(\sum_k \alpha_k^c A^k_{i,j}\right) \]

\(A^k\) is feature map channel \(k\) of the chosen convolution layer, \(H,W\) its spatial dimensions, and \(\alpha_k^c\) the global-average-pooled gradient for class \(c\). The ReLU keeps only evidence that increases the score.

Worked example. Two channels with \(\alpha^c=(0.5,-0.2)\). At one spatial location \(A=(2,5)\): \(\sum_k\alpha_kA_k=0.5\cdot2-0.2\cdot5=1-1=0\), so \(L^c=0\). At a location with \(A=(4,5)\): \(0.5\cdot4-0.2\cdot5=2-1=1\), so \(L^c=1\). The negative channel cancels the positive one only where it is strong.

3 · SmoothGrad

\[ S_{\text{SG}}(x)=\frac{1}{K}\sum_{k=1}^{K} \left|\frac{\partial y^c}{\partial x}\Big|_{x+\varepsilon_k}\right|, \qquad \varepsilon_k\sim\mathcal{N}(0,\sigma^2 I) \]

\(K\) is the number of noisy copies, \(\varepsilon_k\) is Gaussian pixel noise with standard deviation \(\sigma\), and the absolute value is taken before averaging in this course's implementation. Smoothing removes isolated single-pixel spikes while keeping broad regions whose gradient survives perturbation.

Worked example. At one pixel, three noisy copies give saliencies \(2.8, 3.2, 2.9\). Then \(S_{\text{SG}}=(2.8+3.2+2.9)/3=8.9/3=2.967\), compared with the clean value \(3.0\). A pixel whose gradient jumps from \(0\) to \(5\) under tiny noise would average near \(2\) — it is not reliably important.

Lab: saliency on an editable image

This widget owns a 6×6 image and owns its scorer's weights — a linear scorer or a 3×3 convolution plus ReLU. Click or use the arrow and +/− keys on the image to change a pixel; every heatmap cell is the gradient computed by backpropagating through those exact weights. The SmoothGrad toggle perturbs with a fixed seeded RNG, so the same image always produces the same map.

In an ordinary PyTorch model you get the same map by calling out.backward() on the class logit and reading input.grad. The lab implements the two small backward rules explicitly so nothing is hidden: linear \(\partial y/\partial x=W\), and ReLU-conv \(\partial y/\partial x_{i,j}=\sum_{\text{active patches}}W_{u,v}\).

Code: hooks for saliency and Grad-CAM

import torch
from torch import nn

model = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d((4, 4)),
    nn.Flatten(), nn.Linear(32 * 4 * 4, 10),
)
model.eval()                              # disable dropout and use population BN stats
x = torch.randn(1, 3, 64, 64, requires_grad=True)   # (N, C, H, W)
score = model(x)[0, 3]                    # logit of class 3, NOT softmax probability
score.backward()
saliency = x.grad.abs()[0].sum(dim=0)     # (H, W): collapse channels, take magnitude
print("image", tuple(x.shape), "saliency", tuple(saliency.shape))

# ---- Grad-CAM on the last convolution layer -------------------------------
activations, grads = [], []
def fwd_hook(module, inp, out):
    activations.append(out.detach())      # (1, 32, 4, 4)
def bwd_hook(module, gin, gout):
    grads.append(gout[0].detach())        # (1, 32, 4, 4)

handle_f = model[4].register_forward_hook(fwd_hook)
handle_b = model[4].register_backward_hook(bwd_hook)
score.backward(retain_graph=True)
alpha = grads[0].mean(dim=(2, 3), keepdim=True)      # (1, 32, 1, 1)
cam = torch.relu((alpha * activations[0]).sum(dim=1))  # (1, 4, 4)
cam = torch.nn.functional.interpolate(cam.unsqueeze(1), size=(64, 64),
                                      mode="bilinear", align_corners=False)
print("cam", tuple(cam.shape))            # (1, 1, 64, 64)
handle_f.remove(); handle_b.remove()

# ---- SmoothGrad: K perturbed backward passes ------------------------------
K, sigma = 8, 0.15
acc = torch.zeros_like(saliency)
for _ in range(K):
    xp = (x.detach() + sigma * torch.randn_like(x)).requires_grad_(True)
    model(xp)[0, 3].backward()
    acc += xp.grad.abs()[0].sum(dim=0) / K
print("smoothgrad", tuple(acc.shape))

Use the logit, not the softmax probability: softmax couples classes, so a change in another class's score would move the probability even when this class's evidence did not. Model mode matters too — dropout in train() makes two backward passes disagree.

Common mistakes

Forgetting model.eval()

Random dropout masks make the heatmap a function of the RNG state, not of the image. Switch to eval mode before any attribution pass.

Saliency on softmax output

The probability of class \(c\) depends on all logits. Use the logit \(y^c\) for a map that describes evidence for that class alone.

Wrong upsampling for CAM

Nearest-neighbour upsampling produces blocky boundaries; bilinear produces smooth ones. State which you used — the underlying \(4\times4\) map is the actual result.

Over-interpreting noise

A sharp single-pixel hotspot can be an adversarial direction of the local linearisation. Run a label-randomisation sanity check before calling it evidence.

Debug this

Saliency is exactly zero everywhere, while the network's predictions look reasonable. The input tensor was created as x = preprocess(image) with no further flags.

Show the likely cause and the fix

The input does not require gradients. Create it as x = preprocess(image).requires_grad_(True) (or call x.requires_grad_() before the forward pass), then backpropagate from the logit. If a with torch.no_grad() block wraps the forward pass, remove that too — no graph means no gradient path back to the image.

Another common cause: reading x.grad after a second backward pass has accumulated into it. Call x.grad = None between attribution runs.

Summary

1 · Saliency is \(|∂y^c/∂x|\): for \(y=2x_1-3x_2+0.5x_3\) the map is \((2,3,0.5)\).
2 · SmoothGrad averages absolute gradients over noisy copies; \((2.8+3.2+2.9)/3=2.967\) at one pixel.
3 · Grad-CAM weights late feature maps by pooled gradients; check eval mode, use logits, and randomise labels as a sanity test.

Cheat sheet — M6·03

  • \(S_{ij}=|\partial y^c/\partial x_{ij}|\); signed map keeps the sign.
  • SmoothGrad: \(S_{\text{SG}}=\frac1K\sum_k|\partial y^c/\partial(x+\varepsilon_k)|\).
  • Grad-CAM: \(\alpha_k^c=\frac{1}{HW}\sum_{ij}\partial y^c/\partial A^k_{ij}\); \(L^c=\mathrm{ReLU}(\sum_k\alpha_k^cA^k)\).
  • Use logits, model.eval(), and state the upsampling mode.
  • Sanity checks: random labels, random weights, compare classes.
