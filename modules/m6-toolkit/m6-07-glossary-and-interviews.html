Intuition: definitions versus explanations

A definition tells you what a thing is; an interview answer tells you what it is for and what breaks without it. "Gradient clipping limits the norm of a gradient" is a definition. "Without it, one large batch gradient can multiply every parameter by a huge step" is an explanation. Read the bank by trying to answer aloud before opening a solution.

The print stylesheet expands every <details> element, so printing this page produces a question sheet followed immediately by its answers — no hidden text.

In an interview, state the formula, then the failure mode it prevents. The second sentence is what separates memorisation from understanding.

The math of a filter

Let \(N\) be the number of glossary terms in the data file and \(m(q)\) the number whose name or definition contains the query \(q\). The displayed coverage fraction is

\[ f(q)=\frac{m(q)}{N} \]

Here \(q\) is the search string, \(m(q)\) the matched term count and \(N\) the total term count; both counts are computed live from DL.GLOSSARY.

Worked example. If the file contains \(N=69\) terms and a query matches \(m=7\), then \(f=7/69=0.1014\), displayed as about \(10\%\). The chip filter applies the same fraction after restricting to one category: a category with 12 terms and 3 matches yields \(3/12=0.25\).

Interview question bank — 60 questions

M0 · Foundations (9 questions)

1. Why can a single neuron not compute XOR?

Its boundary is \(w_1x_1+w_2x_2+b=0\), one straight line. XOR's two positive corners are diagonally opposite, so no single line can put both on one side and both negatives on the other. A hidden layer with nonlinear activations creates multiple half-planes and solves it.

2. How many parameters does a 2→4→1 MLP with ReLU hidden units have?

17. The first layer has \(2\cdot4+4=12\) (weights plus biases) and the output layer \(4\cdot1+1=5\). ReLU itself has no learned parameters.

3. Why is a nonlinearity necessary between linear layers?

Composing affine maps gives another affine map: \(W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)\). Without a nonlinearity, depth adds no expressive power at all.

4. When should you use BCEWithLogitsLoss instead of BCELoss?

When the model outputs logits (pre-sigmoid). BCEWithLogitsLoss fuses the sigmoid and log into one numerically stable operation; BCELoss expects probabilities in \((0,1)\). Using both applies sigmoid twice and saturates the loss.

5. What is the gradient of cross-entropy with respect to logits?

For softmax cross-entropy with target index \(y\), \(\partial\mathcal L/\partial z=\mathrm{softmax}(z)-\mathbf 1_y\). The fused formulation cancels the softmax Jacobian and is numerically simpler than differentiating the log of a probability.

6. Write the plain SGD update and define each symbol.

\(\theta\leftarrow\theta-\eta\nabla_\theta\mathcal L\), where \(\theta\) are parameters, \(\eta\) the learning rate and \(\nabla_\theta\mathcal L\) the gradient of the mean loss. The minus sign moves downhill because the gradient points uphill.

7. What is the PyTorch momentum convention?

\(v\leftarrow\beta v+\nabla_\theta\mathcal L\) and \(\theta\leftarrow\theta-\eta v\): the gradient is added directly to velocity, without the \((1-\beta)\) factor used in some other frameworks. \(\beta\) is usually about 0.9.

8. How does AdamW differ from Adam with L2 regularisation?

AdamW applies weight decay directly to the parameters, \(\theta\leftarrow\theta-\eta(\hat m/(\sqrt{\hat v}+\epsilon)+\lambda\theta)\), instead of adding \(\lambda\theta\) to the gradient. Decoupling keeps the decay from being distorted by the adaptive denominator \(\sqrt{\hat v}\).

9. Compare Xavier and He initialisation variances.

Xavier draws weights with variance \(2/(D_{\text{in}}+D_{\text{out}})\), suited to tanh/sigmoid-like activations; He uses \(2/D_{\text{in}}\), suited to ReLU because roughly half the units are zero. Their goal is to keep activation variance roughly constant across layers.

M1 · Convolutional networks (9 questions)

10. Give the Conv2d output-size formula and define its symbols.

\(H'=\lfloor(H+2P-D(K-1)-1)/S\rfloor+1\), with \(H\) the input size, \(P\) padding, \(K\) kernel size, \(D\) dilation and \(S\) stride. The same formula applies to width with \(W\).

11. How many parameters does a 3×3 conv with 3 input and 16 output channels have, including bias?

448. Each of the 16 output channels has a \(3\cdot3\cdot3=27\)-weight kernel, giving \(16\cdot27=432\) weights plus 16 biases.

12. What does NCHW mean and why does it matter?

Batch, Channels, Height, Width — the tensor layout used throughout this course. An image batch has shape \((N,C,H,W)\), a conv weight \((C_{\text{out}},C_{\text{in}},K_H,K_W)\) and a feature map \((N,C_{\text{out}},H',W')\). Writing NHWC by mistake transposes every shape calculation.

13. What is the receptive field of two stacked 3×3 convolutions with stride 1?

5×5. The first layer sees 3 input pixels; the second combines three neighbouring outputs of the first, adding two more pixels on each axis: \(3+2=5\). With dilation the added span is \(D(K-1)\) instead of \(K-1\).

14. What does a 1×1 convolution do?

It mixes channels at each spatial position without changing \(H,W\). It can reduce or expand channel count cheaply and, followed by a nonlinearity, adds a per-pixel MLP — as used in bottleneck blocks.

15. How do max pooling and average pooling differ?

Max pooling keeps the largest activation in each window and can discard small but meaningful signals; average pooling takes the mean and smooths. Both use the same output-size formula with \(K\) and \(S\) and no learned parameters.

16. Write the BatchNorm transform and say what changes at evaluation.

\(\hat x=(x-\mu_B)/\sqrt{\sigma_B^2+\epsilon}\), \(y=\gamma\hat x+\beta\). During training \(\mu_B,\sigma_B^2\) come from the batch; at evaluation the running estimates are used, so the output no longer depends on other batch members.

17. Why do residual connections help very deep networks train?

The identity path \(y=F(x)+x\) gives gradients a direct route to earlier layers, avoiding repeated multiplication by small Jacobians. It also makes a block easy to initialise as near-identity, so adding depth initially cannot degrade the function.

18. How do you fine-tune a pretrained classifier on a new task?

Replace the final head to match the new class count, often freeze early layers first, and train with a much smaller \(\eta\) than pretraining (for example 1e-4 rather than 1e-2). Unfreeze progressively and keep the same normalisation and preprocessing used during pretraining.

M2 · Sequences and NLP (9 questions)

19. Write the vanilla RNN recurrence.

\(\mathbf h_t=\tanh(\mathbf x_t W_{xh}+\mathbf h_{t-1}W_{hh}+\mathbf b_h)\); the output may be \(\hat{\mathbf y}_t=\mathrm{softmax}(\mathbf h_tW_{hy}+\mathbf b_y)\). \(W_{xh},W_{hh}\) are shared across all timesteps.

20. Why is BPTT unstable and expensive?

Unrolling \(T\) steps means backpropagating through a chain of repeated Jacobian multiplications, so gradients can shrink or explode exponentially in \(T\). The unrolled graph also uses memory proportional to sequence length; truncation limits both effects.

21. What do the LSTM gates do?

\(f_t\) forgets part of the previous cell state, \(i_t\) controls the candidate \(\tilde c_t\), \(o_t\) controls what the cell exposes as hidden state, and \(c_t=f_tc_{t-1}+i_t\tilde c_t\). The additive cell path prevents the repeated squashing that causes vanishing gradients.

22. How does a GRU differ from an LSTM?

A GRU has two gates, the update \(z_t\) and reset \(r_t\), and no separate cell state; an LSTM has three gates plus \(c_t\). GRUs have fewer parameters and often train faster with similar performance on smaller datasets.

23. Write the attention formula and explain the \(1/\sqrt{d_k}\) factor.

\(\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(QK^\top/\sqrt{d_k})V\). Scores are dot products of \(d_k\)-dimensional vectors, whose variance grows with \(d_k\); dividing by \(\sqrt{d_k}\) restores roughly unit variance so softmax does not saturate.

24. What are the shapes in multi-head attention?

With batch \(N\), heads \(H_{\text{heads}}\), length \(T\) and \(d_k=D/H_{\text{heads}}\): \(Q,K,V\) are \((N,H_{\text{heads}},T,d_k)\), scores \((N,H_{\text{heads}},T,T)\), output \((N,H_{\text{heads}},T,d_k)\), concatenated to \((N,T,D)\).

25. Why add positional encoding to token embeddings?

Self-attention is permutation-equivariant, so without position information it cannot distinguish word order. The sinusoidal scheme uses \(PE_{(pos,2i)}=\sin(pos/10000^{2i/D})\) and the paired cosine, giving each position a unique, smoothly varying vector.

26. What is teacher forcing?

During training, the decoder receives the ground-truth previous token instead of its own prediction. It stabilises early training and lets all timesteps be processed in parallel; at inference the model must use its own outputs, which can cause exposure bias.

27. Why use subword tokenization?

Word-level vocabularies become huge and suffer out-of-vocabulary words; character-level sequences become very long. Subwords such as BPE balance a manageable vocabulary with the ability to compose unseen words from known pieces.

M3 · Generative models (8 questions)

28. Write the GAN minimax objective.

\(\min_G\max_D\,\mathbb E_{x\sim p_{\text{data}}}[\log D(x)]+\mathbb E_{\mathbf z}[\log(1-D(G(\mathbf z)))]\). \(D\) tries to separate real from generated samples; \(G\) tries to fool \(D\). At equilibrium the generated distribution matches the data distribution.

29. Why use the non-saturating generator loss?

Instead of minimising \(\mathbb E\log(1-D(G(z)))\), maximise \(\mathbb E\log D(G(z))\). When \(D\) is confident and correctly rejects generated samples, the original loss saturates near zero gradient; the non-saturating version keeps a strong signal.

30. What is mode collapse?

The generator produces only a few distinct outputs that all fool the discriminator, ignoring most of the data distribution. Signs are low sample diversity despite a good discriminator score; remedies include minibatch discrimination, unrolling, WGAN-GP and diverse architectures.

31. What changes in WGAN-GP?

The discriminator becomes a 1-Lipschitz critic whose output is not squeezed by a sigmoid, and a gradient penalty encourages \(\lVert\nabla_{\hat x}D(\hat x)\rVert\approx1\) on interpolations between real and fake samples. This gives smoother gradients and less mode collapse than weight clipping.

32. How should FID be read?

Lower is better. It compares the mean and covariance of Inception features of real and generated image sets; it needs enough samples (thousands) to be stable, and scores from different feature extractors or sample sizes are not comparable.

33. What are the DCGAN design rules?

Use strided convolutions in the discriminator and transposed convolutions in the generator, batch normalisation in both, ReLU in the generator and LeakyReLU in the discriminator, and a tanh output for images scaled to \([-1,1]\). Avoid fully connected layers and pooling.

34. How does CycleGAN train without paired images?

It learns mappings \(G_{AB}\) and \(G_{BA}\) with adversarial losses plus cycle consistency: \(G_{BA}(G_{AB}(x))\approx x\) and \(G_{AB}(G_{BA}(y))\approx y\). The cycle loss removes the need for matching pairs.

35. What is a minimal GAN sanity check?

Fix a noise vector and inspect samples throughout training; check sample diversity, not only the loss curves; verify the discriminator does not reach near-perfect accuracy instantly. Also confirm the generator's gradient norm is non-zero — otherwise \(D\) has won and \(G\) is not learning.

M4 · Autoencoders and transformers (9 questions)

36. What does the bottleneck of an autoencoder force?

A narrow latent code limits how much information can pass through, so the network must learn a compressed representation useful for reconstructing the input. Reconstruction error alone, however, does not guarantee a semantically useful code.

37. What does a VAE encoder output?

Parameters of a distribution, usually \(\mu\) and \(\log\sigma^2\), rather than a single vector. A latent sample is drawn as \(\mathbf z=\mu+\sigma\odot\epsilon\) with \(\epsilon\sim\mathcal N(0,I)\), so the encoder is probabilistic.

38. Write the ELBO and explain its two terms.

\(\mathcal L=\mathbb E_{q_\phi(z|x)}[\log p_\theta(x|z)]-D_{\mathrm{KL}}(q_\phi(z|x)\Vert p(z))\). The first term rewards accurate reconstruction; the second keeps the posterior close to the prior, acting as a regulariser.

39. Why is the reparameterisation trick necessary?

Sampling directly from \(q_\phi(z|x)\) is a nondifferentiable operation with respect to \(\phi\). Writing \(z=\mu+\sigma\epsilon\) moves randomness to a parameter-free variable so gradients can flow through \(\mu\) and \(\sigma\).

40. What does \(\beta > 1\) do in a \(\beta\)-VAE?

It multiplies the KL term, increasing pressure for an isotropic, factorised latent space. This often improves disentanglement at the cost of reconstruction quality; \(\beta=1\) recovers the standard ELBO.

41. How do BERT and GPT differ in attention direction?

BERT is an encoder with bidirectional self-attention, trained with masked token prediction, so each token sees both left and right context. GPT is a decoder with a causal mask, so each token can attend only to previous positions — appropriate for autoregressive generation.

42. Why does masked language modelling work?

Hiding a fraction of tokens and predicting them from both directions forces the model to build contextual representations rather than memorise left-to-right n-grams. It also lets every masked position contribute a supervised signal in the same pass.

43. What is LoRA's core idea?

Freeze the pretrained weight matrix \(W\) and train a low-rank update \(\Delta W=BA\) with rank \(r\ll D\). Only \(A\) and \(B\) are trainable, which cuts trainable parameters and checkpoint size dramatically while keeping inference mergeable into \(W\).

44. Why anneal the KL weight in a VAE?

Starting with a small \(\beta\) lets reconstruction learning establish a useful encoder before the KL pressure forces the posterior toward the prior. Ramping \(\beta\) to 1 reduces posterior collapse, where the decoder ignores the latent code.

M5 · Segmentation and Kaggle (8 questions)

45. Give IoU and Dice and their relationship.

\(\mathrm{IoU}=|A\cap B|/|A\cup B|\) and \(\mathrm{Dice}=2|A\cap B|/(|A|+|B|)\). They are linked by \(\mathrm{Dice}=2\,\mathrm{IoU}/(1+\mathrm{IoU})\), so Dice is always at least as large as IoU for the same masks.

46. Why does U-Net concatenate encoder features into the decoder?

Pooling loses spatial detail needed for precise boundaries. Skip connections bring high-resolution early feature maps to the corresponding decoder stage, localising edges while deeper features supply semantic context.

47. Write the transposed-convolution output size formula.

\(H'=(H-1)S-2P+D(K-1)+\text{output\_padding}+1\), where \(S\) is stride, \(P\) padding, \(D\) dilation and \(K\) kernel size. Unlike the forward conv formula, stride multiplies \(H-1\).

48. What is the key idea of a fully convolutional network?

Replace the classifier's fully connected layers with convolutions so the network accepts arbitrary spatial sizes and outputs a dense prediction map. Upsampling then restores the input resolution for per-pixel labels.

49. What does Mask R-CNN add to Faster R-CNN?

A parallel mask prediction branch on each region of interest, and RoIAlign to avoid the quantisation of RoI Pooling. It therefore produces both a class/box and a pixel-level mask per detected object.

50. Why is class imbalance severe in segmentation?

Background often occupies most pixels, so a model can score high accuracy while missing small foreground objects. Weighted cross-entropy, Dice loss or focal loss force the optimizer to care about the rare class.

51. How does panoptic segmentation differ from semantic segmentation?

Semantic segmentation assigns one class to every pixel but does not distinguish separate instances of that class. Panoptic segmentation assigns both a semantic class and, for countable objects, an instance ID — it is the union of semantic and instance segmentation.

52. What leakage ruins a Kaggle-style validation score?

Group leakage: the same entity or closely related image appears in train and validation. Use GroupKFold for repeated entities and a chronological split for time series; target-encoding statistics must be computed inside each fold.

M6 · Advanced toolkit (8 questions)

53. Which random sources must be seeded in a PyTorch run?

Python's random, NumPy's global generator, the torch CPU generator and the CUDA generator (all devices). DataLoader workers need a seeded generator and worker_init_fn; cuDNN benchmark mode and nondeterministic kernels must also be disabled for bitwise replay.

54. What is the effective batch size and why divide the loss?

\(B_{\text{eff}}=B\cdot A\cdot W\) for per-device batch \(B\), accumulation steps \(A\) and workers \(W\). Dividing each micro-batch loss by \(A\) makes the accumulated gradient the mean over the larger batch; DDP then averages the gradients across workers.

55. Why does AMP use a loss scale?

fp16 gradients smaller than roughly \(6\times10^{-5}\) underflow to zero. Multiplying the loss by a power-of-two scale \(S\) moves gradients into range; after backward they are divided by \(S\), and clipping must happen after that unscaling step.

56. Define input saliency and say which score to differentiate.

\(S_{ij}=|\partial y^c/\partial x_{ij}|\), with \(y^c\) the class logit. Using the logit isolates evidence for class \(c\); the softmax probability also changes when other classes' logits change, which muddies the attribution.

57. What does SmoothGrad change?

It averages absolute gradients over several noisy copies of the input, \(S_{\text{SG}}(x)=\frac1K\sum_k|\partial y^c/\partial(x+\epsilon_k)|\). This suppresses isolated single-pixel spikes that are unstable under tiny perturbations.

58. Write the affine quantisation map and its error bound.

\(q=\operatorname{clip}(\operatorname{round}(x/s)+z)\), \(\hat x=s(q-z)\). If no clipping occurs, \(|x-\hat x|\le s/2\), since rounding changes \(x/s\) by at most half a step. Clipping invalidates the bound because out-of-range values are replaced by an endpoint.

59. What is the expected cross-entropy at initialisation for \(C\) balanced classes?

About \(\ln C\), because near-zero logits give \(p_c\approx1/C\). Thus \(0.693\) is correct for binary and \(2.303\) for ten classes. A mismatch points to label or head problems; a value that never falls points to gradient or learning-rate problems.

60. Why call model.eval() before export or attribution?

Eval mode disables dropout randomness and makes batch normalisation use running statistics instead of batch statistics. Both otherwise make two forward passes on the same input disagree, which breaks ONNX parity checks and reproducible saliency maps.

Common mistakes

Answering with a definition only

"Attention is a weighted average" is true but incomplete. Say what the weights are and why the scaling factor exists.

Mixing up metric directions

Lower FID is better; higher IoU, Dice, precision, recall and mAP are better. State the direction before quoting any number.

Ignoring shape conventions

Weights are \((C_{\text{out}},C_{\text{in}},K_H,K_W)\) and images are NCHW. An answer that silently uses NHWC will get attention and conv shapes wrong.

Forgetting the failure mode

For nearly every concept there is a matching bug: no nonlinearity, no scaler, no eval mode, no seed. Naming it demonstrates understanding.

Debug this

In an interview you say "my model does not converge, so I will switch from SGD to Adam". The interviewer asks what you checked first. What is the better answer?

Show the likely cause and the fix

Check the pipeline before the optimizer: loss at init against \(\ln C\), whether one batch can be overfit, label range and dtype, gradient norms, and the learning-rate range. If those pass, tune \(\eta\) before switching optimizers. Changing optimizers first mixes a hyperparameter change with an undiagnosed implementation bug.

If you do switch to Adam, reduce the learning rate relative to your SGD setting — Adam's default \(10^{-3}\) is not a drop-in replacement for SGD's \(0.1\).
