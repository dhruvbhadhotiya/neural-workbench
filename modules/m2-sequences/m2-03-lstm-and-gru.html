LSTM and GRU: gates that choose what to remember

— · Lesson 3 of 7 · Exact math labs

A plain RNN overwrites its memory at every step. An LSTM adds a second state with an additive update, so a gradient can travel many steps without being repeatedly squashed.

Objectives

  • Write and evaluate all six LSTM equations and all three GRU equations.
  • Explain what each gate does and why the cell state preserves gradients.
  • Count parameters for both cells and choose bidirectional or stacked configurations.
  • Verify a library LSTM against a hand-written cell and read its output shapes.

You know this from ML → here it becomes

A vanilla RNN has one memory \(\mathbf{h}_t\) and one update — it must overwrite the past to write the present. Think of an LSTM as adding an internal notebook \(\mathbf{c}_t\) with three switches: erase, write and read. The switches are learned functions of the current input and previous hidden state.

Intuition: an additive memory lane

The cell state is updated by addition, \(c_t = f_t c_{t-1} + i_t \tilde c_t\), not by a squash. If the forget gate \(f_t\approx1\) and the input gate \(i_t\approx0\), the cell is copied almost unchanged, and \(\partial c_t/\partial c_{t-1}\approx1\). A gradient riding this lane does not shrink by 0.5 at every step — which is the failure diagnosed in lesson 02.

The hidden state \(\mathbf{h}_t\) is still a filtered, bounded view of the cell, used as the output of the cell and as the signal fed to the next step's gates. This split — long-lived cell, short-lived hidden — is the core design.

Gates are learned multipliers between 0 and 1. The forget gate controls an additive path, so an LSTM can preserve a gradient across hundreds of steps that would vanish in a tanh RNN.

The math

0 · Symbols

Symbols used in this lesson

  • \(D\): input width; \(H\): hidden width; \(t\): timestep; \(\mathbf{x}_t\in\mathbb{R}^{D}\); \(\mathbf{h}_t\in\mathbb{R}^{H}\); \(\mathbf{c}_t\in\mathbb{R}^{H}\).
  • \(f_t\): forget gate; \(i_t\): input gate; \(o_t\): output gate; \(\tilde{\mathbf{c}}_t\): candidate cell; all in \(\mathbb{R}^{H}\).
  • \(z_t\): GRU update gate; \(r_t\): GRU reset gate; \(\tilde{\mathbf{h}}_t\): GRU candidate.
  • \(\mathbf{W},\mathbf{U}\): input and recurrent weight matrices; \(\mathbf{b}\): bias; \(\sigma(x)=1/(1+e^{-x})\).

1 · The six LSTM equations

\[ \mathbf{f}_t = \sigma(\mathbf{x}_t\mathbf{W}_f + \mathbf{h}_{t-1}\mathbf{U}_f + \mathbf{b}_f) \qquad \text{(forget)} \] \[ \mathbf{i}_t = \sigma(\mathbf{x}_t\mathbf{W}_i + \mathbf{h}_{t-1}\mathbf{U}_i + \mathbf{b}_i) \qquad \text{(input)} \] \[ \tilde{\mathbf{c}}_t = \tanh(\mathbf{x}_t\mathbf{W}_c + \mathbf{h}_{t-1}\mathbf{U}_c + \mathbf{b}_c) \qquad \text{(candidate)} \] \[ \mathbf{c}_t = \mathbf{f}_t\odot\mathbf{c}_{t-1} + \mathbf{i}_t\odot\tilde{\mathbf{c}}_t \qquad \text{(cell update)} \] \[ \mathbf{o}_t = \sigma(\mathbf{x}_t\mathbf{W}_o + \mathbf{h}_{t-1}\mathbf{U}_o + \mathbf{b}_o) \qquad \text{(output)} \] \[ \mathbf{h}_t = \mathbf{o}_t\odot\tanh(\mathbf{c}_t) \qquad \text{(hidden output)} \]

\(\odot\) is elementwise multiplication. Write the six lines in that order: three gates, the cell, the output gate, the hidden state.

Worked scalar step. Take pre-activations \(a_f=2\), \(a_i=1\), \(a_o=1.5\), \(a_g=0.8\), with \(c_{t-1}=1\). Then

\[ f_t=\sigma(2)=\tfrac{1}{1+e^{-2}}=0.8808,\quad i_t=\sigma(1)=0.7311,\quad o_t=\sigma(1.5)=0.8176,\quad \tilde c_t=\tanh(0.8)=0.6640 \] \[ c_t = 0.8808\cdot1 + 0.7311\cdot0.6640 = 0.8808+0.4855 = 1.3663 \] \[ h_t = 0.8176\cdot\tanh(1.3663) = 0.8176\cdot0.8779 = 0.7177 \] \[ \frac{\partial c_t}{\partial c_{t-1}} = f_t = 0.8808 \quad\text{vs}\quad \frac{\partial h_t}{\partial h_{t-1}}\approx o_t(1-\tanh^2 c_t)\cdot f_t = 0.8176(1-0.7707)(0.8808)=0.1653 \]

Even in this modest example the cell path retains about 88% of the gradient per step while the hidden path keeps about 17% — over 20 steps that is the difference between memory and amnesia.

2 · The three GRU equations

\[ \mathbf{z}_t = \sigma(\mathbf{x}_t\mathbf{W}_z + \mathbf{h}_{t-1}\mathbf{U}_z + \mathbf{b}_z) \qquad \text{(update gate)} \] \[ \mathbf{r}_t = \sigma(\mathbf{x}_t\mathbf{W}_r + \mathbf{h}_{t-1}\mathbf{U}_r + \mathbf{b}_r) \qquad \text{(reset gate)} \] \[ \tilde{\mathbf{h}}_t = \tanh(\mathbf{x}_t\mathbf{W}_h + (\mathbf{r}_t\odot\mathbf{h}_{t-1})\mathbf{U}_h + \mathbf{b}_h) \] \[ \mathbf{h}_t = (1-\mathbf{z}_t)\odot\mathbf{h}_{t-1} + \mathbf{z}_t\odot\tilde{\mathbf{h}}_t \]

(Four displayed lines: three gate/candidate computations plus the interpolation; the "three equations" name refers to the update, reset and candidate gates, with the final interpolation written out explicitly.)

Worked with the same numbers and \(h_{t-1}=0.5\): \(z_t=\sigma(2)=0.8808\), \(r_t=\sigma(1)=0.7311\), \(\tilde h_t=\tanh(0.8+0.7311\cdot0.5)=\tanh(1.1656)=0.8229\), so \(h_t=(1-0.8808)(0.5)+0.8808(0.8229)=0.0596+0.7248=0.7844\).

3 · Parameter counts

In a PyTorch cell, input and recurrent weights for one gate together form a \((D+H)\times H\) matrix, plus \(H\) biases: \(D H + H^2 + H\) numbers per gate. An LSTM has four gates; a GRU has three:

\[ |\theta|_{\mathrm{LSTM}} = 4(DH+H^2+H),\qquad |\theta|_{\mathrm{GRU}} = 3(DH+H^2+H) \]

Worked for \(D=3,H=4\): one gate is \(3\cdot4+4^2+4=12+16+4=32\), so LSTM has \(4\cdot32=128\) parameters and GRU has \(3\cdot32=96\). A vanilla RNN with the same widths has 32.

4 · Bidirectional and stacked cells

A bidirectional layer runs one cell forwards and one backwards, then concatenates their hidden states: output width \(2H\). It is useful when the whole sentence is available (classification, tagging) and invalid for streaming, where the future is unseen. Stacking \(L\) layers feeds layer \(\ell+1\) the outputs of layer \(\ell\); apply dropout between layers, not on the last one.

Shape check: \(N=8, T=10, D=3, H=4\), num_layers=2, bidirectional=True gives output \((8,10,8)\) (because \(2H=8\)) and h_n \((2\cdot2,8,4)=(4,8,4)\): the first axis is layers × directions.

Code

The manual cell below uses PyTorch's actual parameters, so the printed states match the library to numerical precision. The Keras tab shows the same stacked bidirectional cell. 

import torch
from torch import nn

torch.manual_seed(0)

N, T, D, H = 8, 10, 3, 4
x = torch.randn(N, T, D)
lstm = nn.LSTM(D, H, num_layers=2, batch_first=True,
               bidirectional=True, dropout=0.1)

out, (h_n, c_n) = lstm(x)
print(out.shape)    # (8, 10, 8)  -- 2*H because bidirectional
print(h_n.shape)    # (4, 8, 4)   -- layers * directions, N, H
print(c_n.shape)    # (4, 8, 4)
print("params:", sum(p.numel() for p in lstm.parameters()))

# Verify a single unidirectional cell by hand against the library.
cell = nn.LSTMCell(D, H)
h = torch.zeros(N, H)
c = torch.zeros(N, H)
for t in range(T):
    h, c = cell(x[:, t], (h, c))
out_lib, (h_lib, c_lib) = cell(x, (torch.zeros(N, H), torch.zeros(N, H)))
print("manual == library:", torch.allclose(h, h_lib) and torch.allclose(c, c_lib))
# Recurrent param count for this cell: 4*(D*H + H*H + H) = 4*(12+16+4) = 128

# GRU has three gates instead of four.
gru = nn.GRU(D, H, batch_first=True)
print("GRU params:", sum(p.numel() for p in gru.parameters()))  # 3*(D*H+H*H+H) = 96
import tensorflow as tf

tf.random.set_seed(0)

N, T, D, H = 8, 10, 3, 4
x = tf.random.normal((N, T, D))

# Keras sequences are (batch, time, features); no image layout is involved.
layer = tf.keras.layers.LSTM(H, return_sequences=True, dropout=0.1,
                             recurrent_dropout=0.0)
out = layer(x)
print(out.shape)            # (8, 10, 4)

stacked = tf.keras.Sequential([
    tf.keras.layers.LSTM(H, return_sequences=True),
    tf.keras.layers.Dropout(0.1),
    tf.keras.layers.LSTM(H, return_sequences=True, go_backwards=True),
])
print(stacked(x).shape)     # (8, 10, 4)

# A bidirectional layer concatenates the two directions: width 2*H = 8.
bi = tf.keras.layers.Bidirectional(tf.keras.layers.LSTM(H, return_sequences=True))
print(bi(x).shape)          # (8, 10, 8)
print("LSTM params:", layer.count_params())  # 4*(D*H + H*H + H) = 128

Common mistakes

Last timestep with right padding

With right padding, out[:, -1] is a pad state. Pack the sequence using true lengths, or index with lengths − 1.

Forgetting h0 and c0

The cell needs both states. Passing only h0 to an LSTM raises an error; reusing an old c0 silently mixes unrelated sequences.

Bidirectional on streaming data

A backward cell needs future tokens. It is fine for offline classification and wrong for autoregressive generation or live prediction.

Stacking without dropout

Multi-layer cells overfit quickly. Put dropout between layers (dropout=0.1 for num_layers>1), not on the final output.

Debug this

A reader reports: “h_n has shape (4, N, H) but my code expects (2, N, H).” The model in the listing above was configured with two layers.

Show the likely cause and the fix

Both settings are active: the first axis is num_layers × num_directions. With num_layers=2 and bidirectional=True that is \(2\times2=4\). Either reshape with h_n.view(num_layers, 2, N, H), or take the two directions of the top layer with h_n[-2:] and concatenate them into a \((N,2H)\) vector. Do not simply slice h_n[:2] — that gives the forward direction of both layers, not both directions of the last layer.

Also check that batch_first=True is set; otherwise the shape interpretation changes again.

Summary

1 · LSTM: three gates, an additive cell update c_t = f_t c_{t−1} + i_t ĉ_t, then h_t = o_t tanh(c_t).
2 · GRU merges cell and hidden into an interpolation controlled by z_t, with r_t gating the candidate; it uses 3 rather than 4 gate blocks.
3 · With D=3,H=4 that is 128 versus 96 parameters; bidirectional doubles output width and h_n's first axis is layers × directions.

Cheat sheet — M2·03

  • \(f_t=\sigma(x_tW_f+h_{t-1}U_f+b_f)\); \(i_t,o_t\) analogous; \(\tilde c_t=\tanh(\cdot)\).
  • \(c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t\); \(h_t=o_t\odot\tanh(c_t)\); \(\partial c_t/\partial c_{t-1}=f_t\).
  • GRU: \(z_t=\sigma(\cdot)\), \(r_t=\sigma(\cdot)\), \(\tilde h_t=\tanh(x_tW_h+(r_t\odot h_{t-1})U_h+b_h)\), \(h_t=(1-z_t)h_{t-1}+z_t\tilde h_t\).
  • Parameters per gate: \(DH+H^2+H\). LSTM = 4×; GRU = 3×. For D=3,H=4: 128 and 96.
  • Bidirectional output width \(2H\); \(h_n\) shape \((L\cdot\text{directions},N,H)\).
  • Worked: a_f=2 → f=0.8808, a_i=1 → i=0.7311, c_{t−1}=1, ĉ=0.6640 → c_t=1.3663, h_t=0.7177.
