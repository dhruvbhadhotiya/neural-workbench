Embeddings: a lookup table that learns meaning

— · Lesson 5 of 7 · Exact math labs

One-hot vectors are orthogonal: every word is equally far from every other. An embedding replaces them with learned coordinates, so “king” and “queen” can end up near each other — and the whole model becomes a table lookup plus a recurrence.

Objectives

  • Read an embedding matrix as a lookup and count its parameters.
  • Contrast CBOW with skip-gram and write the negative-sampling objective.
  • Compute cosine similarity by hand and interpret an analogy result carefully.
  • Enumerate exact skip-gram (centre, context) pairs for a given window and stride.

You know this from ML → here it becomes

A one-hot feature column has no notion of similarity: the dot product of two different one-hots is zero. An embedding is just a linear layer applied to that one-hot — but trained so that words appearing in similar contexts get similar rows.

Intuition: a trainable dictionary

The embedding matrix \(E\in\mathbb{R}^{V\times D}\) has one row per token and \(D\) numbers per row. Looking up token \(w\) means selecting row \(w\). In a neural text model, this replaces the one-hot input with a compact vector and is trained by backpropagation just like any other weight.

Word2Vec trained such tables with two shallow objectives. CBOW predicts the centre word from its surrounding words; skip-gram predicts each surrounding word from the centre. Skip-gram gives more training examples for rare words, at higher cost.

Embeddings are a lookup table whose rows are learned. “Meaning” here means geometric proximity produced by distributional training — not a definition.

The math

0 · Symbols

Symbols used in this lesson

  • \(V\): vocabulary size; \(D\): embedding width; \(E\in\mathbb{R}^{V\times D}\): embedding matrix.
  • \(\mathbf{u}_w\): vector for the centre word \(w\); \(\mathbf{v}_c\): vector for a context word \(c\); these are two rows of related tables.
  • \(K\): number of negative samples; \(p\): probability; \(\sigma\): logistic function; \(\cos\): cosine similarity.

1 · Lookup is a matrix product

\[ \mathbf{v}_w = \mathrm{onehot}(w)\,E \]

Worked: \(V=3,D=2\) with \(E=\begin{bmatrix}0.1&0.2\\1.0&-0.5\\0.3&0.7\end{bmatrix}\). For token index 1, \(\mathrm{onehot}=(0,1,0)\) and \((0,1,0)E=(1.0,-0.5)\) — exactly row 1. The table holds \(V D = 3\cdot2=6\) parameters; for \(V=30{,}000, D=512\) it holds \(15{,}360{,}000\).

2 · Skip-gram and negative sampling

\[ p(c\mid w) = \frac{\exp(\mathbf{v}_c\cdot\mathbf{u}_w)} {\sum_{c'=1}^{V}\exp(\mathbf{v}_{c'}\cdot\mathbf{u}_w)} \]

Worked with u = (1,0) and three candidate dot products 2, 1, −1:

\[ \frac{e^2}{e^2+e^1+e^{-1}}=\frac{7.3891}{10.4753}=0.7057,\quad \frac{2.7183}{10.4753}=0.2595,\quad \frac{0.3679}{10.4753}=0.0351 \]

The full softmax touches all \(V\) words per example. Negative sampling replaces it with a binary decision for the true context and \(K\) sampled non-contexts:

\[ \mathcal{L}_{sg} = -\log\sigma(\mathbf{v}_c\cdot\mathbf{u}_w) - \sum_{k=1}^{K}\log\sigma(-\mathbf{v}_{n_k}\cdot\mathbf{u}_w) \]

Worked with \(K=1\), \(\mathbf{u}_w=(1,0)\), true context \(\mathbf{v}_c=(2,1)\) and negative \(\mathbf{v}_n=(-1,0)\): \(\mathbf{v}_c\cdot\mathbf{u}_w=2\), \(\sigma(2)=0.8808\), \(-\log(0.8808)=0.127\); \(-\mathbf{v}_n\cdot\mathbf{u}_w=1\), \(\sigma(1)=0.7311\), \(-\log(0.7311)=0.313\). Total \(\mathcal{L}_{sg}=0.127+0.313=0.440\).

GloVe instead factorizes global co-occurrence counts, and FastText adds subword vectors so rare or unseen words can be composed from pieces.

3 · Cosine similarity and analogies

\[ \mathrm{cos}(\mathbf{a},\mathbf{b}) = \frac{\mathbf{a}\cdot\mathbf{b}}{\lVert\mathbf{a}\rVert\lVert\mathbf{b}\rVert} = \frac{\sum_i a_i b_i}{\sqrt{\sum_i a_i^2}\sqrt{\sum_i b_i^2}} \]

Worked with \(\mathbf{v}_{king}=(3,1)\) and \(\mathbf{v}_{queen}=(2.8,2.6)\): dot \(=3\cdot2.8+1\cdot2.6=11\); \(\lVert king\rVert=\sqrt{10}=3.1623\); \(\lVert queen\rVert=\sqrt{7.84+6.76}=\sqrt{14.6}=3.8210\); \(\cos=11/(3.1623\cdot3.8210)=11/12.083=0.9104\).

The famous analogy arithmetic is \(\mathbf{v}_{king}-\mathbf{v}_{man}+\mathbf{v}_{woman} \approx \mathbf{v}_{queen}\). In 3-D, with \(\mathbf{v}_{king}=(3,1,0.5)\), \(\mathbf{v}_{man}=(1,0,0.2)\), \(\mathbf{v}_{woman}=(0.8,1.6,0.4)\), the result is \((3-1+0.8,\;1-0+1.6,\;0.5-0.2+0.4)=(2.8,2.6,0.7)\), chosen to equal the hand-built \(\mathbf{v}_{queen}\) exactly. This is a demonstration on hand-built numbers, not a learned model or a measured benchmark. Real analogies are approximate and depend on the training corpus.

Code

In PyTorch, nn.Embedding is the lookup table. The first listing proves it equals a one-hot matrix multiply; the second trains a tiny skip-gram model on a toy corpus. Row 0 is reserved for padding. 

import torch
from torch import nn

torch.manual_seed(0)

# 1) Embedding lookup == one-hot matmul.
E = nn.Embedding(num_embeddings=5, embedding_dim=3, padding_idx=0)
ids = torch.tensor([2, 4])
print(E(ids).shape)                      # (2, 3)
onehot = torch.nn.functional.one_hot(ids, num_classes=5).float()
print(torch.allclose(E(ids), onehot @ E.weight))   # True
print("parameters:", sum(p.numel() for p in E.parameters()))  # 15

# 2) A tiny skip-gram loop on a built-in toy corpus (no downloads).
corpus = "the quick brown fox jumps over the lazy dog".split()
vocab = ["<pad>"] + sorted(set(corpus))
stoi = {w: i for i, w in enumerate(vocab)}
data = [stoi[w] for w in corpus]

centre = nn.Embedding(len(vocab), 8, padding_idx=0)
context = nn.Embedding(len(vocab), 8, padding_idx=0)
opt = torch.optim.SGD(list(centre.parameters()) + list(context.parameters()), lr=0.1)

pairs = []
for i, c in enumerate(data):
    for j in range(max(0, i - 2), min(len(data), i + 3)):
        if j != i:
            pairs.append((c, data[j]))   # 30 pairs for radius 2 on 9 tokens

for step in range(200):
    c, ctx = pairs[step % len(pairs)]
    u, v = centre(torch.tensor([c])), context(torch.tensor([ctx]))
    # Negative sampling: one random non-context word.
    neg = torch.tensor([(c + 7 + step) % len(vocab)])
    vn = context(neg)
    pos = torch.nn.functional.logsigmoid((u * v).sum())       # log σ(v·u)
    negl = torch.nn.functional.logsigmoid(-(u * vn).sum())    # log σ(−v_n·u)
    loss = -(pos + negl)
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 50 == 0:
        print(step, round(loss.item(), 4))

print("pairs:", len(pairs), "vocab:", len(vocab))

Common mistakes

Embedding dimension too small or large

\(D=2\) cannot encode enough distinctions; a huge \(D\) with little data memorizes noise and bloats the \(V D\) table. Choose \(D\) with validation, not by habit.

Not tying input/output weights

In a language model, the input embedding and the output projection can share one matrix. Leaving them untied doubles parameters and can weaken the learned geometry.

Training on a tiny corpus

Fifty sentences cannot produce meaningful general-purpose embeddings. Either use a pretrained table or accept that the vectors only encode those fifty sentences.

Confusing context and target

In skip-gram the centre is the input and the window words are targets; in CBOW it is reversed. Swapping them changes what the vectors mean.

Debug this

A reader reports: “nn.Embedding(1000, 64) throws an index error when the batch contains token ID 1000.”

Show the likely cause and the fix

Valid IDs are \(0,\dots,V-1\). A table with 1000 rows accepts IDs 0 through 999; ID 1000 is off by one. Either build the vocabulary with 1000 entries and remap the offending token, or create nn.Embedding(1001, 64, padding_idx=0). Check that the tokenizer's vocabulary size and the model's num_embeddings come from the same object — do not hard-code one and compute the other.

Reserve row 0 for <pad> and pass padding_idx=0 so its gradient stays zero.

Summary

1 · An embedding matrix \(E\in\mathbb{R}^{V\times D}\) is a learned lookup: onehot(w)E selects row w.
2 · Skip-gram predicts context from centre; negative sampling costs −log σ(v·u) − log σ(−vₙ·u), here 0.440.
3 · Cosine measures angle, not magnitude: cos(king, queen) = 11/(√10·√14.6) = 0.9104 on the hand-built vectors.

Cheat sheet — M2·05

  • Lookup: \(\mathbf{v}_w=\mathrm{onehot}(w)E\), \(E\in\mathbb{R}^{V\times D}\), \(VD\) parameters.
  • Skip-gram softmax: \(p(c\mid w)=\exp(v_c\cdot u_w)/\sum_{c'}\exp(v_{c'}\cdot u_w)\).
  • Negative sampling: \(-\log\sigma(v_c\cdot u_w)-\sum_{k=1}^{K}\log\sigma(-v_{n_k}\cdot u_w)\).
  • Cosine: \(\cos(a,b)=(a\cdot b)/(\lVert a\rVert\lVert b\rVert)\); worked value 0.9104.
  • CBOW: context → centre. Skip-gram: centre → context. GloVe: co-occurrence matrix. FastText: character n-grams.
  • Valid embedding IDs are \(0,\dots,V-1\); reserve row 0 for padding.
