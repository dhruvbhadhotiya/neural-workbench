Backpropagation through time and vanishing gradients

— · Lesson 2 of 7 · Exact math labs

The unrolled RNN is just a very deep chain. Backprop through that chain multiplies the same Jacobian again and again — and repeated multiplication is where memory breaks.

Objectives

  • Derive BPTT as the ordinary chain rule applied along the unrolled graph.
  • Explain vanishing and exploding gradients as a product of Jacobians.
  • Use the spectral radius to predict which regime a recurrent weight is in.
  • Apply global-norm gradient clipping at the right point in the training step.

You know this from ML → here it becomes

Backprop in an MLP multiplies one Jacobian per layer. BPTT multiplies the same recurrent Jacobian \(J=\partial\mathbf{h}_t/\partial\mathbf{h}_{t-1}\) once per timestep. Nothing is new mathematically — only the depth is now the sequence length, and the factor being repeated is shared.

Intuition: a long product of small numbers

If a gradient passes through 20 steps and each step shrinks it by a factor of 0.5, only \(0.5^{20}\approx 9.5\times10^{-7}\) of the signal reaches the start. The early tokens cannot learn. If each step instead multiplies by 1.2, the gradient grows to \(1.2^{20}\approx 38\), and an optimizer step blows the weights up. Both failures come from the same place: a repeated product, not from a bad learning rate.

Clipping does not fix vanishing — you cannot amplify a signal that has become numerically indistinguishable from zero. It fixes exploding gradients by rescaling the whole gradient vector before the optimizer sees it. Architectural changes (the LSTM cell path) fix the vanishing side.

Depth in time is depth in the graph. A recurrent Jacobian with norm below 1 kills long-range gradients; above 1 it detonates them; clipping is the guard rail for the second case.

The math

0 · Symbols

Symbols used in this lesson

  • \(T\): sequence length; \(\mathbf{h}_t\in\mathbb{R}^{H}\): hidden state at step \(t\); \(\mathcal{L}\): scalar loss.
  • \(J_t=\partial\mathbf{h}_t/\partial\mathbf{h}_{t-1}\in\mathbb{R}^{H\times H}\): recurrent Jacobian at step \(t\).
  • \(s\): scalar weight scale used in the worked example; \(\phi'\): derivative of the activation.
  • \(\rho(J)\): spectral radius (largest absolute eigenvalue) of \(J\); \(g\): flattened gradient vector; \(\tau\): clipping threshold; \(\lVert\cdot\rVert\): Euclidean norm.

1 · Backpropagation through time

\[ \frac{\partial\mathcal{L}}{\partial\mathbf{h}_1} = \frac{\partial\mathcal{L}}{\partial\mathbf{h}_T} \prod_{t=2}^{T}\frac{\partial\mathbf{h}_t}{\partial\mathbf{h}_{t-1}} = \frac{\partial\mathcal{L}}{\partial\mathbf{h}_T}\; J_T J_{T-1}\cdots J_2 \]

In the scalar shortcut, each Jacobian is \(J = s\,\phi'\). With \(s=0.5\), a tanh unit at zero (\(\tanh'(0)=1\)), and \(T=20\):

\[ J = 0.5\cdot 1 = 0.5,\qquad \left\lVert\frac{\partial\mathcal{L}}{\partial\mathbf{h}_1}\right\rVert = 0.5^{20} = (0.5^{10})^2 = (0.0009766)^2 = 9.5367\times10^{-7} \]

With a sigmoid activation, \(\sigma'(0)=0.25\), so \(J=0.5\cdot0.25=0.125\) and the same 20 steps give \(0.125^{20}\approx 8.7\times10^{-19}\) — effectively zero. With \(s=1.2\) and tanh, \(J=1.2\) and \(1.2^{20}\approx 38.34\). The lab below recomputes this product for any combination of scale, length and activation.

2 · Spectral radius, not single entries

For a matrix Jacobian, the asymptotic behaviour of \(J^k\) is governed by its eigenvalues. The spectral radius is

\[ \rho(J)=\max_i |\lambda_i|,\qquad \lambda_i=\text{eigenvalues of }J \]

Worked scalar check: \(J=[0.5]\) has \(\rho=0.5\), so \(\rho^{20}=0.5^{20}=9.54\times10^{-7}\). For \(J=\begin{bmatrix}0.9&0\\0&0.2\end{bmatrix}\), \(\rho=0.9\) and \(\rho^{20}=0.9^{20}\approx0.122\): the large eigenvalue dominates, which is why reading only the smallest entry of a matrix is misleading. Random recurrent matrices with \(\rho>1\) typically explode; with \(\rho<1\) they forget.

3 · Gradient clipping by global norm

\[ g \leftarrow g\cdot\min\!\left(1,\frac{\tau}{\lVert g\rVert}\right), \qquad \lVert g\rVert=\sqrt{\sum_i g_i^2} \]

Worked example: \(g=(3,4)\), \(\tau=1\). Then \(\lVert g\rVert=\sqrt{9+16}=5\), the factor is \(\min(1,1/5)=0.2\), and \(g\leftarrow(0.6,0.8)\), whose norm is exactly \(\sqrt{0.36+0.64}=1\). If \(\lVert g\rVert\le\tau\) (say \(g=(0.3,0.4)\), \(\tau=1\)), the factor is 1 and nothing changes. Clipping the whole vector preserves its direction; clipping each component independently does not.

4 · Truncated BPTT

Instead of backpropagating all \(T\) steps, train on chunks of \(K\) steps and detach the state at each boundary. This bounds the product length (cheap memory, stable gradients) at the cost of ignoring dependencies older than \(K\). For \(K=20\) and \(J=0.5\), the longest learned dependency has gradient \(9.5\times10^{-7}\); choosing \(K\) is a bias–compute trade-off, not a mathematical fix for vanishing.

The practical diagnostic is a gradient-norm curve: log \(\lVert g\rVert\) every optimizer step. A value that grows by roughly a constant factor per step signals exploding gradients; a value pinned near zero on long sequences signals vanishing.

Code

Clipping happens after loss.backward() and before optimizer.step(). clip_grad_norm_ computes the norm over all parameters together and returns the original norm. 

import torch
from torch import nn

torch.manual_seed(0)

rnn = nn.RNN(4, 8, batch_first=True)
head = nn.Linear(8, 2)
opt = torch.optim.Adam(list(rnn.parameters()) + list(head.parameters()), lr=0.01)
loss_fn = nn.CrossEntropyLoss()

def grad_norm(params):
    sq = sum((p.grad.detach() ** 2).sum() for p in params if p.grad is not None)
    return sq.sqrt().item()

x = torch.randn(16, 25, 4)        # (N, T, D)
y = torch.randint(0, 2, (16,))    # (N,)
params = list(rnn.parameters()) + list(head.parameters())

for step in range(200):
    opt.zero_grad()                       # clear old gradients FIRST
    out, _ = rnn(x)                       # (N, T, H)
    logits = head(out[:, -1])             # many-to-one: final state
    loss = loss_fn(logits, y)
    loss.backward()
    before = grad_norm(params)
    torch.nn.utils.clip_grad_norm_(params, max_norm=1.0)   # global norm
    after = grad_norm(params)
    opt.step()                            # step AFTER clipping
    if step % 40 == 0:
        print(step, "loss", round(loss.item(), 4),
              "grad norm", round(before, 3), "->", round(after, 3))

# Manual equivalent of clip_grad_norm_ for g = (3, 4), tau = 1:
g = torch.tensor([3., 4.])
tau = 1.0
factor = min(1.0, tau / (g.norm() + 1e-12))
print((g * factor).tolist(), (g * factor).norm().item())   # [0.6, 0.8], 1.0

Common mistakes

Clipping after step()

Once the optimizer has moved the weights, rescaling .grad changes nothing. Clip between backward() and step().

Clipping per parameter

Applying a separate norm to every weight tensor changes the update direction and still allows a large global norm. clip_grad_norm_ uses all parameters at once.

Blaming the learning rate

A loss that turns NaN after hundreds of steps with a growing gradient norm is an exploding-gradient problem. Lowering \(\eta\) without clipping only delays it.

Clipping the wrong quantity

Clipping each element to \([-1,1]\) is value clipping, not norm clipping. It is a different operation and does not guarantee \(\lVert g\rVert\le\tau\).

Debug this

A reader reports: “the loss is fine for ~300 steps, then becomes NaN. I use \(\eta=0.1\) on an 8-step RNN and no clipping.” The relevant loop is the listing above with two lines removed.

Show the likely cause and the fix

The recurrent Jacobian occasionally has norm above 1; over 8 steps the product grows and \(\eta=0.1\) takes an oversized step, producing NaN. Restore torch.nn.utils.clip_grad_norm_(params, max_norm=1.0) immediately after loss.backward(), and use a modest learning rate such as 0.01. Log grad_norm every step: if it rises geometrically, clipping is masking — not curing — an initialization or scaling problem.

Also check that zero_grad() is called each iteration; accumulated gradients look exactly like exploding gradients.

Summary

1 · BPTT is the chain rule along the unrolled graph: ∂L/∂h₁ = (∂L/∂h_T)·J_T⋯J₂.
2 · A recurrent factor below 1 vanishes (0.5²⁰ ≈ 9.5×10⁻⁷); above 1 explodes (1.2²⁰ ≈ 38).
3 · Clip the global gradient norm between backward() and step(); g ← g·min(1, τ/‖g‖).

Cheat sheet — M2·02

  • \(\partial\mathcal{L}/\partial\mathbf{h}_1=(\partial\mathcal{L}/\partial\mathbf{h}_T)\prod_{t=2}^{T}J_t\).
  • Scalar shortcut: \(J=s\,\phi'\), \(\tanh'(0)=1\), \(\sigma'(0)=0.25\), ReLU active branch \(=1\).
  • \(\rho(J)=\max|\lambda|\); \(\rho<1\) vanishes, \(\rho>1\) explodes.
  • Worked: \(0.5^{20}=9.5367\times10^{-7}\); \(1.2^{20}\approx38.34\).
  • Clip: \(g\leftarrow g\min(1,\tau/\lVert g\rVert)\); \(g=(3,4),\tau=1\rightarrow(0.6,0.8)\).
  • Order: zero_grad → forward → backward → clip → step.
