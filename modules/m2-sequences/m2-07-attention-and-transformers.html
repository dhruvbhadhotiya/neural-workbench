Attention and transformers: let every token look back

— · Lesson 7 of 7 · Exact math labs

An RNN compresses the past into one vector. Attention keeps every token accessible and learns how much to read from each one — with weights you can compute and display.

Objectives

  • Compute scaled dot-product attention by hand for three tokens with \(d_k=2\).
  • Explain the roles of Q, K and V, multi-head attention and the causal mask.
  • Compute sinusoidal positional encodings and verify the relative-offset property.
  • Match a hand-written attention function to nn.MultiheadAttention and sketch an encoder block.

You know this from ML → here it becomes

A weighted average of features is familiar: \(\mathbf{z}=\sum_t \alpha_t \mathbf{v}_t\). Attention simply learns the weights \(\alpha_t\) from the current query and all keys, then uses them to mix values. The soft, differentiable lookup replaces a hard index.

Intuition: soft lookup over tokens

Think of a dictionary whose keys are compared to a query by dot product. A large dot product means “relevant”. Softmax turns those scores into weights that sum to 1, and the output is the weighted mixture of the values. Every position produces its own query, so each token decides what to read. Crucially, all positions are computed in parallel: no sequential recurrence.

A decoder must not peek at the future. Its causal mask sets scores for later positions to \(-\infty\) before the softmax, making their weights exactly zero.

Attention is content-based retrieval: scores from Q·Kᵀ, weights from a row softmax, output from weights times V. Removing the sequence bottleneck costs \(O(T^2)\) pairwise scores.

The math

0 · Symbols

Symbols used in this lesson

  • \(Q\in\mathbb{R}^{T\times d_k}\): queries; \(K\in\mathbb{R}^{T\times d_k}\): keys; \(V\in\mathbb{R}^{T\times d_v}\): values; \(T\): sequence length.
  • \(d_k\): key/query width; \(H_{heads}\): number of heads; \(D\): model width; \(d_k = D/H_{heads}\).
  • \(\mathrm{pos}\): token position; \(i\): dimension-pair index; \(PE\): positional encoding matrix.

1 · Scaled dot-product attention

\[ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V \]

Worked example. Let \(T=3\), \(d_k=2\), and \(\mathbf{q}_1=(1,0),\mathbf{q}_2=(0,1),\mathbf{q}_3=(1,1)\) with the same three vectors as keys. The unscored dot products are

\[ QK^\top=\begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix},\qquad \sqrt{d_k}=\sqrt2=1.4142,\qquad S=\frac{QK^\top}{\sqrt2}=\begin{bmatrix}0.7071&0&0.7071\\0&0.7071&0.7071\\0.7071&0.7071&1.4142\end{bmatrix} \]

Row 1: \(e^{0.7071}=2.0281\), \(e^{0}=1\), so the sum is \(5.0562\) and the weights are \((0.4011,\,0.1978,\,0.4011)\). Row 2 gives \((0.1978,\,0.4011,\,0.4011)\). Row 3 has sum \(2.0281+2.0281+4.1133=8.1695\), so \((0.2483,\,0.2483,\,0.5035)\). Each row sums to 1; multiplying by \(V\) produces one \(d_v\)-vector per query. Without the \(1/\sqrt{d_k}\) scale, the logits are larger and the softmax saturates.

2 · Multi-head attention

\[ \mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_{H})\,W_O, \qquad \mathrm{head}_h=\mathrm{Attention}(QW_Q^{(h)},KW_K^{(h)},VW_V^{(h)}) \]

Worked: \(D=8\), \(H_{heads}=4\) gives \(d_k=8/4=2\). Each head produces a \(T\times2\) output; concatenating four heads restores \(T\times8\), and \(W_O\) mixes them. Heads can specialize — one may track syntax, another coreference — but that is an empirical tendency, not a guarantee. The score cost is \(O(T^2 d_k)\) per head, hence \(O(T^2 D)\) overall: a 3-token sentence needs 9 scores (3 × 3), an 8-token one needs 64.

3 · Positional encoding

\[ PE_{(\mathrm{pos},2i)}=\sin\!\left(\frac{\mathrm{pos}}{10000^{2i/D}}\right),\qquad PE_{(\mathrm{pos},2i+1)}=\cos\!\left(\frac{\mathrm{pos}}{10000^{2i/D}}\right) \]

Worked for \(i=0\) (so \(\omega=1\)): \(PE(2)=(0.9093,-0.4161)\), \(PE(5)=(-0.9589,0.2837)\). For a shift \(k=3\), the rotation matrix \(R'=\begin{bmatrix}\cos 3&\sin 3\\-\sin 3&\cos 3\end{bmatrix} =\begin{bmatrix}-0.9900&0.1411\\-0.1411&-0.9900\end{bmatrix}\) gives \(R'PE(2)=(-0.9900\cdot0.9093+0.1411(-0.4161),\ -0.1411\cdot0.9093-0.9900(-0.4161)) =(-0.9589,0.2837)=PE(5)\). Also \(PE(p)\cdot PE(p+3)=\cos 3=-0.9900\) for every \(p\): the dot product depends only on the offset, which is how a relative position becomes visible.

4 · Encoder and decoder blocks

An encoder block is LayerNorm → multi-head self-attention → residual → LayerNorm → feed-forward → residual. A decoder block inserts a masked self-attention sublayer and a cross-attention sublayer that queries the encoder output. Stacking \(L\) blocks gives a model with no recurrence at all; position information comes only from \(PE\).

Code

The hand-written function uses the library's own projection weights, so its output must match nn.MultiheadAttention numerically. Then a minimal encoder block shows the residual and LayerNorm order. 

import math
import torch
from torch import nn

torch.manual_seed(0)

N, T, D, heads = 2, 4, 8, 2
x = torch.randn(N, T, D)

mha = nn.MultiheadAttention(embed_dim=D, num_heads=heads, batch_first=True)
out, weights = mha(x, x, x, need_weights=True, average_attn_weights=True)
print(out.shape, weights.shape)   # (2,4,8), (2,4,4)

# Hand-written attention using exactly the library's projections.
Wq, Wk, Wv = mha.in_proj_weight.chunk(3, dim=0)
bq, bk, bv = mha.in_proj_bias.chunk(3, dim=0)
Q, K, V = x @ Wq.T + bq, x @ Wk.T + bk, x @ Wv.T + bv
dk = D // heads
Qh = Q.view(N, T, heads, dk).transpose(1, 2)   # (N,H,T,dk)
Kh = K.view(N, T, heads, dk).transpose(1, 2)
Vh = V.view(N, T, heads, dk).transpose(1, 2)
scores = (Qh @ Kh.transpose(-1, -2)) / math.sqrt(dk)
A = scores.softmax(dim=-1)
ctx = A @ Vh                                    # (N,H,T,dk)
ctx = ctx.transpose(1, 2).reshape(N, T, D)
manual = ctx @ mha.out_proj.weight.T + mha.out_proj.bias
print("matches library:", torch.allclose(out, manual, atol=1e-6))
print("weights sum to 1:", A.sum(dim=-1)[0, 0])

class EncoderBlock(nn.Module):
    def __init__(self, D, heads, ff=32):
        super().__init__()
        self.n1 = nn.LayerNorm(D)
        self.att = nn.MultiheadAttention(D, heads, batch_first=True)
        self.n2 = nn.LayerNorm(D)
        self.ff = nn.Sequential(nn.Linear(D, ff), nn.GELU(), nn.Linear(ff, D))
    def forward(self, x):
        h = self.n1(x)
        a, _ = self.att(h, h, h, need_weights=False)
        x = x + a                         # residual around attention
        h = self.n2(x)
        return x + self.ff(h)             # residual around feed-forward

block = EncoderBlock(D, heads)
print("encoder output:", block(x).shape)         # (2, 4, 8)
import tensorflow as tf
import math

tf.random.set_seed(0)

N, T, D, heads = 2, 4, 8, 2
x = tf.random.normal((N, T, D))

att = tf.keras.layers.MultiHeadAttention(num_heads=heads, key_dim=D // heads)
out, w = att(x, x, x, return_attention_scores=True)
print(out.shape, w.shape)                 # (2,4,8), (2,2,4,4)

# Sinusoidal positional encoding (shape (1,T,D) broadcasts over the batch).
pos = tf.cast(tf.range(T)[:, None], tf.float32)
i = tf.cast(tf.range(D // 2)[None, :], tf.float32)
w = tf.pow(tf.constant(10000.0), -2.0 * i / D)
pe = tf.concat([tf.sin(pos * w), tf.cos(pos * w)], axis=-1)
print(pe.shape)                           # (1, 4, 8)
x = x + pe

def encoder_block(x, D, heads, ff=32):
    h = tf.keras.layers.LayerNormalization()(x)
    a = tf.keras.layers.MultiHeadAttention(heads, D // heads)(h, h)
    x = x + a
    h = tf.keras.layers.LayerNormalization()(x)
    h = tf.keras.layers.Dense(ff, activation="gelu")(h)
    return x + tf.keras.layers.Dense(D)(h)

print(encoder_block(x, D, heads).shape)   # (2, 4, 8)

Common mistakes

Forgetting the \(\sqrt{d_k}\) scale

Large dot products push the softmax into a near one-hot distribution and kill gradients. Divide by \(\sqrt{d_k}\), not by \(d_k\).

Mask on the wrong axis

Apply the causal mask to the key positions of each query row, before softmax. Masking query rows or masking after softmax does not implement causality.

Mixing up add and concat

Positional encoding is added to the token embedding so both have width \(D\); the heads are concatenated before \(W_O\). Keep those two operations distinct.

No causal mask in a decoder

Self-attention in a decoder sees future tokens unless masked, which leaks the answer into the prediction and makes generation invalid.

Debug this

A reader reports: “my attention weights are exactly uniform, \(1/T\) everywhere, no matter what the input is.”

Show the likely cause and the fix

Look at the mask first. A mask that marks every position as forbidden makes DL.tensor.softmax return zeros; after any fallback normalization that looks uniform. In PyTorch, filling all scores with -inf produces NaNs in softmax. The causal mask must keep positions \(j\le t\) unmasked for query \(t\) — mask only the strict future. The second candidate is a broken scale: dividing by a huge number collapses all scores to zero, giving exactly uniform weights.

Print one row of raw scores before softmax; it should contain finite, distinct numbers, and exactly one unmasked position for \(t=0\) under a causal mask.

Summary

1 · Attention = softmax(QKᵀ/√d_k)·V; for q₂·k₃=1 and d_k=2 the scaled score is 0.7071.
2 · Multi-head splits D into H heads of width d_k=D/H, concatenates, then applies W_O; cost is O(T²D).
3 · Sinusoidal PE is added to embeddings and satisfies PE(p)·PE(p+k)=cos(kω); decoder attention needs a causal mask.

Cheat sheet — M2·07

  • \(\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(QK^\top/\sqrt{d_k})V\); softmax is per query row.
  • Worked row 1: scores (0.7071, 0, 0.7071) → weights (0.4011, 0.1978, 0.4011).
  • \(d_k = D/H_{heads}\); D=8, H=4 → d_k=2; concatenate all heads then apply \(W_O\).
  • \(PE_{(p,2i)}=\sin(p/10000^{2i/D})\), odd dimensions use cos; added to embeddings.
  • Rotation identity: \(PE(p+k)=R'(k\omega)PE(p)\); dot product = cos(kω), worked −0.9900 for k=3, i=0.
  • Encoder block: LayerNorm → attention → residual → LayerNorm → FFN → residual.
