How to use this module

offline · exact labs · read in order

Double-click a lesson

Everything runs from file://. No server, no account, no CDN. KaTeX is vendored locally and every visual is drawn from numbers computed in your browser.

Read the badge first

Exact math means the numbers are computed live. Illustrative means hand-built values — the analogy and sentiment-trace demos say so explicitly.

Notation is fixed

\(T\) is sequence length, \(H\) hidden width, \(\mathbf{h}_t\) the state; softmax takes logits, and attention scores are \(QK^\top/\sqrt{d_k}\). The same symbols appear in M0–M6.
