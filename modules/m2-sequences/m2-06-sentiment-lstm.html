Sentiment classification with an LSTM, end to end

— · Lesson 6 of 7 · Illustrative trace, exact gate lab

Tokens become IDs, IDs become vectors, vectors become a sequence of hidden states, and the last state becomes one logit per class. This lesson wires those four steps into a runnable script on a toy corpus you can replace with your own data.

Objectives

  • Trace tensor shapes through embedding → LSTM → head with concrete numbers.
  • Handle variable-length sentences with padding, packing and masking.
  • Use class-weighted cross-entropy and evaluate in model.eval() mode.
  • Train a complete LSTM classifier on a tiny built-in corpus, with a clear swap-in point for real data.

You know this from ML → here it becomes

TF-IDF + logistic regression treats a review as a bag of words: “not good” and “good” look almost the same. An LSTM reads in order, so the negation has a chance to change the state before the classifier sees it. The pipeline around it — train split, loss, optimizer, eval — is the same one you already know.

Intuition: the last state is a summary

You can open the gate dashboard from lesson 03 here and feed it a few words one at a time: each token updates the cell state, and the final state holds the accumulated evidence. For classification, we take that final state (or an attention-weighted pool of all states) and apply a linear head. Padding must not contribute, otherwise the “final” state belongs to a pad token.

A classifier needs one vector per sentence. The final hidden state is a learned summary of the prefix; pooling all states is an alternative when early tokens matter more.

The math

0 · Symbols

Symbols used in this lesson

  • N: batch size; T: padded sequence length; V: vocabulary size; D: embedding width; H: hidden width.
  • K: number of classes; ŷ: logits, one score per class; y: the true class index.
  • hₜ: hidden state; ℓₙ: per-example cross-entropy (minus log softmax at the true label); w_y: class weight.

1 · Shape trace

Worked shapes for N=4, T=6, V=50, D=8, H=16, K=2, one bidirectional layer
stepshapearithmetic
token IDs(4, 6)padded batch
embedding(4, 6, 8)V·D = 50·8 = 400 table entries
LSTM output(4, 6, 32)2H = 2·16 = 32
last states concat(4, 32)forward + backward at t = T
head logits(4, 2)32·2 + 2 = 66 parameters

The final hidden state is a function of every input: \[ \mathbf{h}_T = f\!\left(\mathbf{x}_T,\; f\!\left(\mathbf{x}_{T-1},\;\dots f\!\left(\mathbf{x}_1,\mathbf{h}_0\right)\right)\right) \] That nested composition is why one vector can summarize a sentence. If the batch is right-padded, however, the “T-th” token is a pad — use the true length or pack the sequence.

2 · Class-weighted cross-entropy

\[ \mathcal{L} = \frac{\sum_{n=1}^{N} w_{y_n}\,\ell_n}{\sum_{n=1}^{N} w_{y_n}}, \qquad \ell_n=-\log\mathrm{softmax}(\hat{\mathbf y}_n)_{y_n} \]

Worked: two examples, class 0 with per-example loss 0.2 and class 1 with loss 0.4. The positive class is rarer, so its weight is 3 while class 0 has weight 1:

\[ \mathcal{L} = \frac{1\cdot0.2 + 3\cdot0.4}{1+3} = \frac{1.4}{4} = 0.35 \]

Without weights the mean would be 0.30 — the weighted loss penalizes mistakes on the rarer class three times as much.

3 · Last state vs mean pool

\[ \mathbf{z} = \mathbf{h}_T \quad\text{or}\quad \mathbf{z} = \frac{1}{L}\sum_{t=1}^{L}\mathbf{h}_t \]

The hand-built trace below shows the difference with fixed numbers. For i love this film the pooling weights are 0.05, 0.55, 0.15, 0.25 and the token scores are 0, 1, 0.3, 0.7. Two worked lines:

\[ \text{pooled} = 0.55\cdot1 + 0.15\cdot0.3 + 0.25\cdot0.7 = 0.770 \] \[ \hat y = -0.3 + 2.5\cdot0.770 = 1.625,\qquad p=\sigma(1.625)=0.835 \]

Putting all weight on the last token instead gives pooled 0.7, logit 1.45 and probability 0.810. The weights here are hand-built to make the arithmetic visible — no model was trained to produce them.

Code

This is the flagship script: a complete LSTM sentiment classifier on a built-in toy corpus, with no downloads. The marked block is the only part to change for a real dataset. Evaluate with model.eval() and torch.no_grad() so dropout is off. 

import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader
from collections import Counter

torch.manual_seed(0)

# ---- SWAP-IN POINT: replace this tiny built-in corpus with your own (text, label) pairs ----
TRAIN = [
    ("i love this film", 1), ("a wonderful sweet movie", 1),
    ("great acting and a kind story", 1), ("i enjoyed every minute", 1),
    ("this was dull and slow", 0), ("a terrible boring film", 0),
    ("i hated the plot", 0), ("bad acting and a weak script", 0),
]
TEST = [("i love the story", 1), ("a dull and boring movie", 0)]
# ---------------------------------------------------------------------------

def tokenize(s):
    return s.lower().split()

counter = Counter(w for s, _ in TRAIN for w in tokenize(s))  # TRAIN only: no leakage
stoi = {"<pad>": 0, "<unk>": 1}
for w, _ in counter.most_common():
    stoi[w] = len(stoi)

class Reviews(Dataset):
    def __init__(self, rows):
        self.rows = rows
    def __len__(self):
        return len(self.rows)
    def __getitem__(self, k):
        text, y = self.rows[k]
        ids = [stoi.get(w, 1) for w in tokenize(text)] or [1]
        return ids, y

def collate(batch):
    T = max(len(ids) for ids, _ in batch)
    X = torch.full((len(batch), T), 0, dtype=torch.long)   # pad index 0
    lens = torch.tensor([len(ids) for ids, _ in batch])
    y = torch.tensor([lab for _, lab in batch])
    for n, (ids, _) in enumerate(batch):
        X[n, :len(ids)] = torch.tensor(ids)
    return X, lens, y

train_dl = DataLoader(Reviews(TRAIN), batch_size=4, shuffle=True, collate_fn=collate)

class SentimentLSTM(nn.Module):
    def __init__(self, V, D=16, H=16, classes=2):
        super().__init__()
        self.emb = nn.Embedding(V, D, padding_idx=0)
        self.lstm = nn.LSTM(D, H, batch_first=True, bidirectional=True)
        self.head = nn.Linear(2 * H, classes)
    def forward(self, x, lengths):
        e = self.emb(x)                               # (N, T, D)
        packed = nn.utils.rnn.pack_padded_sequence(
            e, lengths.cpu(), batch_first=True, enforce_sorted=False)
        out, (h_n, _) = self.lstm(packed)             # h_n: (2, N, H)
        both = torch.cat((h_n[0], h_n[1]), dim=1)     # (N, 2H)
        return self.head(both)                        # (N, K) logits

model = SentimentLSTM(len(stoi))
weights = torch.tensor([1.0, 3.0])                    # class 1 is rarer here
loss_fn = nn.CrossEntropyLoss(weight=weights)
opt = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(120):
    model.train()
    for X, lens, y in train_dl:
        opt.zero_grad()
        logits = model(X, lens)                       # (N, 2)
        loss = loss_fn(logits, y)                     # logits first, labels second
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        opt.step()
    if epoch % 40 == 0:
        print("epoch", epoch, "loss", round(loss.item(), 4))

model.eval()
with torch.no_grad():
    X, lens, y = collate([(s, lab) for s, lab in TEST])
    pred = model(X, lens).argmax(dim=1)
    print("test predictions:", pred.tolist(), "labels:", y.tolist())

print("embedding params:", model.emb.weight.numel(), "= V*D =", len(stoi), "* 16")
import tensorflow as tf
from collections import Counter

tf.random.set_seed(0)

TRAIN = [
    ("i love this film", 1), ("a wonderful sweet movie", 1),
    ("great acting and a kind story", 1), ("i enjoyed every minute", 1),
    ("this was dull and slow", 0), ("a terrible boring film", 0),
    ("i hated the plot", 0), ("bad acting and a weak script", 0),
]
counter = Counter(w for s, _ in TRAIN for w in s.lower().split())
stoi = {"<pad>": 0, "<unk>": 1}
for w, _ in counter.items():
    stoi[w] = len(stoi)

def encode(text, T=8):
    ids = [stoi.get(w, 1) for w in text.lower().split()][:T]
    return ids + [0] * (T - len(ids))

X = tf.constant([encode(s) for s, _ in TRAIN])
y = tf.constant([lab for _, lab in TRAIN])

model = tf.keras.Sequential([
    tf.keras.layers.Embedding(len(stoi), 16, mask_zero=True, input_length=8),
    tf.keras.layers.Bidirectional(tf.keras.layers.LSTM(16)),
    tf.keras.layers.Dense(2),                       # logits
])
model.compile(
    optimizer=tf.keras.optimizers.Adam(0.01),
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=["accuracy"],
)
model.fit(X, y, epochs=120, verbose=0,
          class_weight={0: 1.0, 1: 3.0})
print(model.evaluate(X, y, verbose=0))
print(model.count_params())

Eight training sentences cannot teach general sentiment — this script demonstrates the plumbing and shapes, not a benchmark. Replace the marked corpus (and raise the epoch count) for a real task.

Common mistakes

Padding not masked

A padded final state obscures the real last token. Pass lengths to pack_padded_sequence or use mask_zero=True in Keras.

batch_first mismatch

Your batch is \((N,T,D)\); the default RNN expects \((T,N,D)\). Set batch_first=True in every layer, including stacked ones.

Embedding without padding index

Without padding_idx=0, pad rows receive gradients and the table learns that “nothing” has meaning. Reserve and freeze row 0.

Evaluating with dropout on

Forgetting model.eval() makes predictions random and lowers measured accuracy. Switch back to model.train() for the next epoch.

Debug this

A reader reports: “training loss falls but accuracy is exactly 50% on my balanced two-class toy set.” The script above was edited in one place.

Show the likely cause and the fix

Check the loss call first. nn.CrossEntropyLoss expects loss_fn(logits, labels) with logits of shape \((N,2)\) and labels \((N,)\). Passing loss_fn(labels, logits) or applying a softmax before the loss changes the target axes; broadcasting can silently accept the wrong shapes and the head learns to predict a constant. The other common edit is computing accuracy from logits.argmax(dim=0) instead of dim=1, which compares across the batch and yields a constant 50% on balanced data.

Print logits.shape, y.shape and one batch of logits.softmax(dim=1) before changing the learning rate.

Check yourself

Summary

1 · The pipeline is token IDs (N,T) → embedding (N,T,D) → LSTM output (N,T,2H) → head logits (N,K).
2 · Use true lengths (packing or a mask) and padding_idx=0 so pads never define the final state.
3 · Weight rare classes in CE, build vocab from train only, and evaluate with model.eval().

Cheat sheet — M2·06

  • Embedding table V·D parameters, row 0 reserved for <pad>.
  • Bidirectional LSTM: output \((N,T,2H)\), h_n \((2,N,H)\); concatenate the two directions.
  • Class-weighted CE: L = Σ w_y·ℓₙ / Σ w_y; worked 1.4/4 = 0.35.
  • Worked logit: pooled 0.770 → ŷ = −0.3 + 2.5·0.770 = 1.625 → p = 0.835.
  • Loop order: zero_grad → forward → loss → backward → clip → step; evaluate in eval() mode without gradients.
  • Vocabulary from TRAIN only; logits shape (N,K), labels shape (N).
