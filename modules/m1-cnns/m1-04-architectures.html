Architectures: from LeNet to ResNet

— · Lesson 4 of 8 · Exact math labs

Architecture is the inductive bias made concrete. Every design family can be checked by two numbers: the shape that comes out and the count of parameters that produced it.

Objectives

  • Trace output shapes through the major CNN families and verify their parameter totals.
  • Explain the residual gradient path y = x + F(x) and the role of 1×1 projections.
  • Compute receptive field by the recursion over kernel sizes and strides.
  • Compute the depthwise-separable cost ratio and read an Inception concatenation.

You know this from ML → here it becomes

Model selection in ML meant choosing between estimators with the same features. Here the architecture decides which features can exist at all — and unlike a benchmark score, its shapes and parameter counts are exactly checkable.

Intuition: a family tree of design choices

LeNet showed that conv → pool → conv → pool → FC works for digits. AlexNet scaled this to ImageNet with larger kernels, ReLU and dropout. VGG asked whether big kernels were needed: two 3×3 convs have a 5×5 receptive span but fewer parameters and one more nonlinearity. ResNet asked whether depth itself was the problem: adding an identity path makes the gradient highway explicit. Inception runs several kernel sizes in parallel and concatenates their outputs; MobileNet and EfficientNet spend parameters and FLOPs more carefully.

Two checkable quantities run through all of them. Parameters come from layer shapes (conv \(C_{out}C_{in}K^2+C_{out}\), FC \(D_{in}D_{out}+D_{out}\), BN \(2C\)). The receptive field is how many input pixels can influence one output pixel — always larger than a single kernel once layers are stacked.

Symbols

\(F\): residual branch function · \(x\): block input · \(y\): block output · \(r_l\): receptive field after layer \(l\) · \(k_l,s_l,d_l\): kernel, stride and dilation of layer \(l\) · \(C,K\): channels and kernel size for the cost ratio.

The math

1 · Residual blocks

\[ y = x + F(x), \qquad \frac{\partial y}{\partial x} = I + \frac{\partial F}{\partial x} \]

Worked scalar check: if the branch Jacobian is \(0.1\), after 20 plain layers a gradient scales as \(0.1^{20}=1.0\times10^{-20}\) (vanished). With skips, each step is \(1+0.1=1.1\), so \(1.1^{20}\approx6.73\). The identity term keeps a direct route from the loss to early layers. When shapes differ (e.g. 64 → 128 channels, stride 2), the skip uses a 1×1 conv to project the input: \(y = W_{proj}x + F(x)\).

2 · Receptive-field recursion

\[ r_l = r_{l-1} + (k_l-1)\, d_l \prod_{i<l} s_i, \qquad r_0 = 1 \]

Worked example, five layers, \(k=3\) everywhere and dilations 1. Strides \((1,2,1,2,1)\): layer 1 gives \(r=1+2\cdot1=3\) (jump 1); layer 2 gives \(3+2\cdot1=5\) (jump becomes 2); layer 3 gives \(5+2\cdot2=9\); layer 4 gives \(9+2\cdot2=13\) (jump 4); layer 5 gives \(13+2\cdot4=\mathbf{21}\). The final output pixel sees a 21×21 input window, not 3×3.

3 · Depthwise-separable cost

\[ \frac{\text{depthwise-separable}}{\text{regular}} = \frac{C K^2 + C C_{out}}{C C_{out} K^2} = \frac{1}{C_{out}} + \frac{1}{K^2} \]

Worked with \(C=C_{out}=64, K=3\): regular \(=9\cdot64\cdot64=36{,}864\); separable \(=9\cdot64 + 64\cdot64 = 576+4{,}096 = 4{,}672\); ratio \(4{,}672/36{,}864 \approx 0.1267\), matching \(1/64+1/9\).

4 · Inception branch concatenation

Four parallel branches on the same (spatially padded) input: a 1×1 conv giving 64 channels; 1×1→96 then 3×3→128; 1×1→16 then 5×5→32; and a 3×3 pool then 1×1→32. With matching stride and padding, each branch keeps \(H\times W\), so concatenation along the channel axis gives \(64+128+32+32 = 256\) output channels, shape \((N,256,H,W)\).

Hands-on labs

Every number below is computed in your browser from the inputs you can change.

Code

import torch
from torch import nn

class BasicBlock(nn.Module):
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.f = nn.Sequential(
            nn.Conv2d(cin, cout, 3, stride, 1, bias=False), nn.BatchNorm2d(cout), nn.ReLU(),
            nn.Conv2d(cout, cout, 3, 1, 1, bias=False), nn.BatchNorm2d(cout),
        )
        # identity fails when shapes change: need a 1x1 projection
        self.skip = (nn.Sequential(nn.Conv2d(cin, cout, 1, stride, bias=False),
                                   nn.BatchNorm2d(cout))
                     if stride != 1 or cin != cout else nn.Identity())
        self.relu = nn.ReLU()

    def forward(self, x):                        # (N, cin, H, W)
        return self.relu(self.f(x) + self.skip(x))  # (N, cout, H/s, W/s)

block = BasicBlock(64, 128, stride=2)
x = torch.randn(2, 64, 56, 56)   # (N, C, H, W)
y = block(x)                     # (2, 128, 28, 28)
print(y.shape)
print("params", sum(p.numel() for p in block.parameters()))

# ResNet-18 stub: stem + 4 stages of 2 blocks each + GAP + fc
stem = nn.Sequential(nn.Conv2d(3, 64, 7, 2, 3, bias=False),
                     nn.BatchNorm2d(64), nn.ReLU(), nn.MaxPool2d(3, 2, 1))
stages = nn.Sequential(BasicBlock(64, 64), BasicBlock(64, 64),
                       BasicBlock(64, 128, 2), BasicBlock(128, 128))
head = nn.Sequential(nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(128, 1000))
print(tuple(head(stages(stem(torch.randn(1, 3, 224, 224)))).shape))  # (1, 1000)

Common mistakes

Skip with mismatched shapes

Adding a (N,64,56,56) tensor to a (N,128,28,28) tensor fails. Use a 1×1 conv with the target stride and channel count in the skip path.

BN placement around the add

ResNet puts BN at the end of each conv branch and adds before the final ReLU. Adding after a BN on the skip changes what the identity path preserves.

Counting a block wrong

ResNet convs use bias=False, so a 3×3 64→64 conv has 9·64·64 = 36,864 parameters (not 36,928); BN adds 2·64 = 128.

RF equals kernel size

Receptive field grows with every layer and multiplies stride jumps. Five 3×3 layers with strides (1,2,1,2,1) reach 21×21, not 3×3.

Debug this

A reader's residual block raises a RuntimeError on the second stage: the add expects matching shapes, but the tensors have 64 and 128 channels.

Show the likely cause and the fix

The downsampling block changed both channels and spatial size, but the skip was still nn.Identity(). Give the skip a 1×1 projection: nn.Conv2d(64, 128, 1, stride=2, bias=False) followed by BatchNorm2d(128). Its cost here is \(1\cdot64\cdot128 = 8{,}192\) parameters — exactly the `layer2.0.downsample` row from tools/params.py.

Guard in code: assert x.shape == skip(x).shape before the add while debugging.

Cheat sheet — M1·04

  • Residual: \(y=x+F(x)\), \(\partial y/\partial x=I+\partial F/\partial x\).
  • Receptive field: \(r_l=r_{l-1}+(k_l-1)d_l\prod_{i<l}s_i\).
  • Worked RF for k=3, strides (1,2,1,2,1): 3 → 5 → 9 → 13 → 21.
  • Depthwise-separable ratio: \(1/C_{out}+1/K^2\); for 64,3 it is 0.1267.
  • Counts from tools/params.py: LeNet 61,706 · AlexNet 61,100,840 · VGG-16 138,357,544 · ResNet-18 11,689,512.
  • BN contributes \(2C\) parameters; ResNet convs use bias=False.
