Training a CNN end to end

— · Lesson 5 of 8 · Exact math labs

Training a CNN is your sklearn pipeline rebuilt from layers and schedules: normalisation becomes BatchNorm, regularisation becomes architecture plus optimizer, and the learning rate becomes a function of step.

Objectives

  • Compute BatchNorm forward on a small batch and explain train versus eval behaviour.
  • Distinguish L1 and L2 regularisation geometrically and in the gradient.
  • Write a warmup-plus-cosine learning-rate schedule and evaluate it at a given step.
  • Assemble a complete CIFAR-style CNN loop with labelled shapes, augmentation and a head.

You know this from ML → here it becomes

Your sklearn pipeline had StandardScaler, GridSearchCV and a fixed optimizer. In deep learning normalisation is a layer with learnable scale and shift; regularisation is a mix of weight decay, dropout, augmentation and schedule — and batch statistics make train and eval genuinely different modes.

Intuition: normalisation as a layer

BatchNorm standardises each channel across the batch and the spatial positions, then applies a learnable scale \(\gamma\) and shift \(\beta\). It lets deeper layers see activations on a consistent scale, and its running statistics make evaluation deterministic. Regularisation is no longer one term: L2 decay pulls weights toward zero, dropout randomly removes activations in training, augmentation changes the inputs, and the LR schedule controls how aggressively the model can fit.

The training loop itself is unchanged from M0: forward, loss, backward, optimizer step. What is new is bookkeeping — calling model.train() and model.eval(), putting augmentation only on the training path, and choosing whether the LR is warm, decayed, or both.

Symbols

\(\mu_B,\sigma_B^2\): batch mean/variance · \(\epsilon\): numerical stabiliser · \(\gamma,\beta\): learned affine parameters · \(\lambda\): L2/weight-decay strength · \(\eta_t\): learning rate at step \(t\) · \(T\): total steps · \(\epsilon_{ls}\): label-smoothing amount · \(\theta\): parameters.

The math

1 · BatchNorm

\[ \hat x = \frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}, \qquad y = \gamma \hat x + \beta \]

Worked on four numbers \(x=(1,2,3,4)\), with \(\epsilon=10^{-5}\), \(\gamma=2\), \(\beta=0.5\): \(\mu_B=2.5\), \(\sigma_B^2=\frac{2.25+0.25+0.25+2.25}{4}=1.25\), \(\sqrt{1.25+10^{-5}}\approx1.11803\). The normalised values are \((-1.3416,-0.4472,0.4472,1.3416)\) and after the affine transform \(y\approx(-2.1833,-0.3944,1.3944,3.1833)\). At eval time \(\mu_B,\sigma_B^2\) are replaced by running averages accumulated during training.

2 · L2 penalty

\[ \mathcal{L}_{\text{total}} = \mathcal{L} + \frac{\lambda}{2}\lVert\theta\rVert^2, \qquad \nabla_\theta \mathcal{L}_{\text{total}} = \nabla_\theta\mathcal{L} + \lambda\theta \]

Worked: with \(\theta=0.8\), \(\lambda=0.01\), the extra gradient is \(0.008\) — a small pull toward zero every step. L1 instead adds \(\lambda\,\mathrm{sign}(\theta)\), which can set weights exactly to zero. In most CNN code “weight decay” in AdamW implements decoupled L2.

3 · Warmup + cosine

\[ \eta_t = \eta_{\min} + \tfrac12(\eta_{\max}-\eta_{\min})\left(1+\cos\frac{\pi t}{T}\right) \]

Worked with \(\eta_{\max}=0.1\), \(\eta_{\min}=10^{-4}\), \(t=50\), \(T=100\): \(\cos(\pi/2)=0\), so \(\eta_{50}=0.0001+0.5\cdot0.0999\cdot1=\mathbf{0.05005}\). Warmup linearly raises \(\eta\) from near zero to \(\eta_{\max}\) over the first \(t_w\) steps, which keeps early updates from destabilising a randomly initialised net.

4 · Label smoothing and clipping

\[ y'_k = \begin{cases}1-\epsilon_{ls} & k=y\\ \epsilon_{ls}/(K-1) & k\ne y\end{cases} \]

Worked with \(K=10\), \(\epsilon_{ls}=0.1\): the true class target is \(0.9\), each of the other nine classes gets \(0.1/9\approx0.0111\). This prevents the model from pushing logits to infinity. Gradient clipping rescales a gradient \(g\) by \(\min(1,\tau/\lVert g\rVert)\); with \(\lVert g\rVert=5,\tau=1\) the gradient is multiplied by \(0.2\).

Code

import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset
import torchvision.transforms as T

# CIFAR-10 path (commented: no downloads in this offline course):
# train = torchvision.datasets.CIFAR10(root="./data", train=True, download=True,
#                                      transform=T.Compose([T.RandomCrop(32, 4),
#                                                           T.RandomHorizontalFlip(),
#                                                           T.ToTensor(),
#                                                           T.Normalize((.5,)*3, (.5,)*3)]))
# Synthetic stand-in with the identical shapes — clearly NOT real CIFAR data:
X = torch.randn(512, 3, 32, 32)             # (N, C, H, W)
y = torch.randint(0, 10, (512,))            # (N,)
train = TensorDataset(X, y)
loader = DataLoader(train, batch_size=64, shuffle=True)

def conv(cin, cout):
    return nn.Sequential(nn.Conv2d(cin, cout, 3, padding=1, bias=False),  # (N,cout,H,W)
                         nn.BatchNorm2d(cout), nn.ReLU())

net = nn.Sequential(conv(3, 32), nn.MaxPool2d(2),      # (N,32,16,16)
                    conv(32, 64), nn.MaxPool2d(2),     # (N,64,8,8)
                    nn.AdaptiveAvgPool2d(1), nn.Flatten(),  # (N,64)
                    nn.Dropout(0.2), nn.Linear(64, 10))     # (N,10) logits

opt = torch.optim.AdamW(net.parameters(), lr=1e-3, weight_decay=1e-4)
steps = 200
for step in range(steps):
    warm = min(1.0, (step + 1) / 20)                    # linear warmup
    cos = 0.5 * (1 + torch.cos(torch.tensor(3.14159265 * step / steps)).item())
    for group in opt.param_groups:
        group["lr"] = 1e-3 * warm * cos                  # warmup + cosine
    xb, yb = next(iter(loader))                          # (64,3,32,32), (64,)
    logits = net(xb)                                     # (64,10)
    loss = nn.functional.cross_entropy(logits, yb, label_smoothing=0.1)
    opt.zero_grad(set_to_none=True)
    loss.backward()
    nn.utils.clip_grad_norm_(net.parameters(), 1.0)
    opt.step()
    if step % 40 == 0:
        print(step, round(loss.item(), 4), round(opt.param_groups[0]["lr"], 6))

# model.train() during the loop; model.eval() + torch.no_grad() for validation.
# AMP: with torch.autocast("cuda", dtype=torch.float16): logits = net(xb)
import tensorflow as tf

# Keras uses NHWC: (N, H, W, C). PyTorch listing above uses NCHW.
# Real CIFAR-10: tf.keras.datasets.cifar10.load_data() — omitted offline.
tf.random.set_seed(0)
X = tf.random.normal((512, 32, 32, 3))       # NCHW equivalent (512,3,32,32)
y = tf.random.uniform((512,), 0, 10, dtype=tf.int32)

augment = tf.keras.Sequential([
    tf.keras.layers.RandomCrop(32, 4),
    tf.keras.layers.RandomFlip("horizontal"),
])

def conv(c):
    return tf.keras.Sequential([
        tf.keras.layers.Conv2D(c, 3, padding="same", use_bias=False),  # (N,H,W,c)
        tf.keras.layers.BatchNormalization(),
        tf.keras.layers.ReLU(),
    ])

inputs = tf.keras.Input((32, 32, 3))
x = augment(inputs)                          # training path only
x = conv(32)(x); x = tf.keras.layers.MaxPooling2D(2)(x)      # (N,16,16,32)
x = conv(64)(x); x = tf.keras.layers.MaxPooling2D(2)(x)      # (N,8,8,64)
x = tf.keras.layers.GlobalAveragePooling2D()(x)              # (N,64)
x = tf.keras.layers.Dropout(0.2)(x)
outputs = tf.keras.layers.Dense(10)(x)                       # (N,10) logits

model = tf.keras.Model(inputs, outputs)
warm = tf.keras.optimizers.schedules.LearningRateSchedule()
class WarmCosine(warm):
    def __init__(self, hi=1e-3, warm_steps=20, total=200):
        super().__init__(); self.hi, self.w, self.T = hi, warm_steps, total
    def __call__(self, step):
        w = tf.minimum(1.0, (step + 1) / self.w)
        c = 0.5 * (1 + tf.cos(3.14159265 * step / self.T))
        return self.hi * w * c
    def get_config(self): return {}

model.compile(optimizer=tf.keras.optimizers.AdamW(WarmCosine(), weight_decay=1e-4),
              loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True,
                                                                 label_smoothing=0.1),
              metrics=["accuracy"])
model.fit(X, y, batch_size=64, epochs=2, verbose=0)

Common mistakes

BN with batch size 1

Batch statistics over one sample and a tiny spatial map are noisy or undefined. Use GroupNorm or frozen BatchNorm for tiny batches.

Forgetting model.eval()

In eval mode BN uses running statistics and dropout is off. Leaving the model in train mode makes validation outputs depend on batch composition.

Decaying BN parameters

Weight decay on gamma/beta and biases is usually skipped; most implementations separate those parameter groups.

Augmenting validation data

Random crops and flips belong on the training path only. Applying them at validation time changes the task and makes scores noisy.

Debug this

A reader reports: training loss falls to nearly zero, but validation accuracy stays near 10% on a balanced 10-class task. One line is wrong.

Show the likely cause and the fix

The labels and loss disagree. Common examples: targets are one-hot of shape \((N,10)\) while CrossEntropyLoss expects class indices \((N,)\); or logits are passed through softmax before a loss that applies log-softmax itself. Print yb.shape, yb.dtype, logits.shape and pass raw logits to the fused loss.

Second check: if validation was run without model.eval(), BN's batch statistics make the score unstable — but that would not pin accuracy exactly at chance.

Summary

1 · BatchNorm normalises with batch statistics in training and running statistics at eval; the worked batch (1,2,3,4) has mean 2.5 and variance 1.25.
2 · Weight decay adds lambda·theta to the gradient, and warmup+cosine sets eta_t = eta_min + ½(eta_max−eta_min)(1+cos(pi t/T)) — 0.05005 at the midpoint of the worked schedule.
3 · A CNN loop is forward → fused loss (with label smoothing) → clip → optimizer step, wrapped in train/eval modes and training-only augmentation.

Cheat sheet — M1·05

  • BatchNorm: \(\hat x=(x-\mu_B)/\sqrt{\sigma_B^2+\epsilon}\), \(y=\gamma\hat x+\beta\).
  • Worked: \(\mu_B=2.5,\ \sigma_B^2=1.25,\ \hat x\approx(-1.34,-0.45,0.45,1.34)\).
  • L2 gradient: \(\nabla\mathcal{L}+\lambda\theta\); \(\lambda=0.01,\theta=0.8\Rightarrow0.008\).
  • Warmup+cosine midpoint: \(\eta=0.05005\) for (0.1, 1e-4, T=100).
  • Label smoothing: \(0.9\) true class, \(0.1/9\) each other class for K=10.
  • Call model.train() / model.eval(); clip by min(1, tau/||g||).
