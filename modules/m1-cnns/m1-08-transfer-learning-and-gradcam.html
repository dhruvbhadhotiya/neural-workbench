Transfer learning and Grad-CAM

— · Lesson 8 of 8 · Exact math labs

Pretrained filters are a reusable feature extractor. Fine-tune them carefully — and when the model makes a prediction, Grad-CAM can tell you which spatial region drove it.

Objectives

  • Choose freeze/unfreeze from dataset size × similarity to the source task.
  • Implement a head swap and parameter groups with different learning rates.
  • Compute Grad-CAM weights alpha_k and the localisation map from gradients.
  • Explain when pretraining hurts and how Grad-CAM differs from plain saliency.

You know this from ML → here it becomes

In ML you would reuse engineered features and refit only the final estimator. Here the learned conv filters are the features: keep them fixed for small datasets, or nudge them with a much smaller learning rate when the new task has enough examples.

Intuition: reuse the filters, replace the head

Early filters trained on a large image corpus detect generic edges and textures; later filters become more task specific. A small, similar dataset is best served by freezing the backbone and training a new head. A large, dissimilar dataset benefits from fine-tuning more layers. A small, dissimilar dataset is the hard case: pretrained features may be misleading, so try both and validate.

Grad-CAM answers “where did the model look?” For a chosen class \(c\), it weights each feature map \(A^k\) by how much a global measure of that map affects the class score. It uses gradients flowing into the final conv layer, so it is more class-specific and spatially coherent than a raw input-gradient saliency map.

Symbols

\(A^k\): feature map of channel \(k\), with \(Z=H W\) positions · \(y^c\): logit for class \(c\) · \(\alpha_k\): Grad-CAM weight for channel \(k\) · \(L^c\): localisation map · \(\eta\): learning rate.

The math

1 · Grad-CAM weights

\[ \alpha_k = \frac{1}{Z}\sum_{i,j}\frac{\partial y^c}{\partial A^k_{ij}}, \qquad L^c = \mathrm{ReLU}\!\left(\sum_k \alpha_k A^k\right), \qquad Z = HW \]

Worked with \(Z=9\) (two 3×3 maps). Let \(A^1\) be all ones and its gradient have a single 1 at the centre: \(\alpha_1=1/9\approx0.1111\). Let \(A^2\) have a single 1 at the centre and its gradient be all ones: \(\alpha_2=9/9=1\). Then \(\alpha_1A^1+\alpha_2A^2\) is 0.1111 at the eight outer cells and \(0.1111+1=1.1111\) at the centre. ReLU leaves these unchanged; dividing by the maximum gives a map with 0.1 on the border and 1.0 at the centre — a localised explanation.

2 · Differential learning rates

Group parameters so the backbone takes a small step and the new head a larger one: \(\eta_{\text{head}}=10\times\eta_{\text{backbone}}\) is a common starting point. Worked: \(\eta_{\text{backbone}}=10^{-4}\) gives \(\eta_{\text{head}}=10^{-3}\). With AdamW, weight decay is usually applied to conv weights but not to BN parameters or biases.

3 · How the hook gathers gradients

Register a forward hook on the target conv layer to store its output \(A\). Register a backward hook to store \(\partial y^c/\partial A\). Global-average the latter over \(i,j\) to get \(\alpha_k\), multiply by \(A^k\), sum over \(k\), then apply ReLU and normalise to \([0,1]\). The result has the spatial size of \(A\), not of the input image, so it is upsampled for display.

Code

import torch
from torch import nn
from torchvision import models

net = models.resnet18(weights=None)      # no download in this offline course
# net = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)  # real pretrained path
net.fc = nn.Linear(net.fc.in_features, 10)   # head swap: (N,512) -> (N,10)

# Freeze the backbone, train the head
for p in net.parameters(): p.requires_grad_(False)
for p in net.fc.parameters(): p.requires_grad_(True)

head_lr, body_lr = 1e-3, 1e-4
opt = torch.optim.AdamW([
    {"params": [p for n, p in net.named_parameters() if n.startswith("fc")], "lr": head_lr},
    {"params": [p for n, p in net.named_parameters() if n.startswith("layer4") and p.requires_grad],
     "lr": body_lr},
], weight_decay=1e-4)

# To fine-tune layer4: unfreeze it, keep earlier layers frozen.
for n, p in net.named_parameters():
    if n.startswith("layer4"): p.requires_grad_(True)
net.eval()   # BatchNorm uses running statistics while the backbone is frozen

# ---- Grad-CAM hooks on the last conv stage ----
acts, grads = {}, {}
def fwd_hook(module, inp, out): acts["A"] = out.detach()   # (N,512,7,7)
def bwd_hook(module, gin, gout): grads["g"] = gout[0]       # (N,512,7,7)
h1 = net.layer4.register_forward_hook(fwd_hook)
h2 = net.layer4.register_full_backward_hook(bwd_hook)

x = torch.randn(1, 3, 224, 224)           # (N,C,H,W)
score = net(x)[0, 3]                       # class c = 3
net.zero_grad(); score.backward()
A, g = acts["A"], grads["g"]               # (1,512,7,7)
alpha = g.mean(dim=(2, 3), keepdim=True)    # (1,512,1,1)
cam = torch.relu((alpha * A).sum(dim=1))   # (1,7,7)
cam = cam / cam.max().clamp_min(1e-9)
h1.remove(); h2.remove()
print(cam.shape)
import tensorflow as tf

base = tf.keras.applications.ResNet50(weights=None, include_top=False,
                                      input_shape=(224, 224, 3))  # no download
# weights="imagenet" is the real pretrained path (skipped offline)
base.trainable = False                      # feature extraction

inputs = tf.keras.Input((224, 224, 3))
x = tf.keras.applications.resnet.preprocess_input(inputs)
x = base(x, training=False)                 # (N, 7, 7, 2048) NHWC
x = tf.keras.layers.GlobalAveragePooling2D()(x)   # (N, 2048)
outputs = tf.keras.layers.Dense(10)(x)            # (N, 10) logits
model = tf.keras.Model(inputs, outputs)
model.compile(optimizer=tf.keras.optimizers.Adam(1e-3),
              loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True))

# Fine-tune the last stage with a 10x smaller learning rate
base.trainable = True
for layer in base.layers[:-20]: layer.trainable = False
model.compile(optimizer=tf.keras.optimizers.Adam(1e-4),
              loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True))

# Grad-CAM: gradient of class score w.r.t. the last conv output
last = base.get_layer("conv5_block3_out")
cam_model = tf.keras.Model(model.inputs, [last.output, model.outputs[0]])
with tf.GradientTape() as tape:
    A, logits = cam_model(tf.random.normal((1, 224, 224, 3)))
    score = logits[:, 3]
grad = tape.gradient(score, A)              # (1,7,7,2048)
alpha = tf.reduce_mean(grad, axis=(1, 2))   # (1,2048)
cam = tf.nn.relu(tf.reduce_sum(alpha[:, None, None, :] * A, axis=-1))  # (1,7,7)
cam = cam / tf.reduce_max(cam)

Common mistakes

BN left in train mode while frozen

Calling model.train() updates BatchNorm running statistics from the new, possibly tiny dataset. Keep eval mode for a frozen backbone or freeze BN statistics explicitly.

High LR on pretrained weights

A learning rate of 0.1 can destroy features that took a large corpus to learn. Use a small backbone LR and a larger head LR, then unfreeze gradually.

Wrong normalisation statistics

Pretrained backbones expect their own per-channel mean/std. Feeding images normalised with a different dataset's statistics degrades features before training starts.

Grad-CAM without ReLU or normalisation

Negative evidence can cancel positive regions; ReLU keeps class-relevant evidence and dividing by the maximum makes the heatmap comparable across examples.

Debug this

A reader fine-tunes a pretrained network with lr=0.1 on 500 images and accuracy collapses below the frozen-baseline result within one epoch.

Show the likely cause and the fix

The learning rate is far too high for borrowed weights. Start with a frozen backbone and a head LR around \(10^{-3}\), then unfreeze the last block with a backbone LR around \(10^{-4}\) — a factor of ten smaller. Verify that preprocessing uses the source model's mean/std and that BatchNorm is in eval mode while frozen.

Also check the head: the original classifier (1000 classes) must be replaced by one matching the new class count, otherwise the output dimensions are wrong.

Check yourself

Summary

1 · Freeze strategy follows dataset size × similarity: frozen head for small/similar data, gradual fine-tuning with low LRs for large or dissimilar data.
2 · Differential LRs and a new head let borrowed features adapt without being destroyed (head 1e-3, backbone 1e-4 in the worked example).
3 · Grad-CAM computes alpha_k = mean gradient of y^c over each feature map, then L^c = ReLU(Σ alpha_k A^k) — the worked 3×3 example gives 0.1 on the border and 1.0 at the centre.

Cheat sheet — M1·08

  • \(\alpha_k=\frac{1}{HW}\sum_{i,j}\partial y^c/\partial A^k_{ij}\).
  • \(L^c=\mathrm{ReLU}(\sum_k\alpha_k A^k)\), then divide by \(\max L^c\).
  • Worked: \(\alpha_1=1/9,\alpha_2=1\Rightarrow\) border 0.1, centre 1.0.
  • Head swap: ResNet-18 GAP → 512 features → Linear(512, n_classes).
  • Differential LR: head \(10^{-3}\), frozen/late backbone \(10^{-4}\).
  • Frozen BatchNorm stays in eval mode; Grad-CAM needs forward + backward hooks.
