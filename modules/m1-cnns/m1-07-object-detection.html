Object detection: boxes, IoU, NMS and anchors

— · Lesson 7 of 8 · Exact math labs

Detection predicts both what and where, with a variable number of objects. The machinery is checkable arithmetic: box overlap, greedy suppression and class-wise precision–recall.

Objectives

  • Contrast two-stage and one-stage detectors and explain anchors.
  • Compute IoU from two boxes by hand and in the lab.
  • Run non-maximum suppression on a small set of scored boxes.
  • Define precision, recall and AP at an IoU threshold without inventing benchmark numbers.

You know this from ML → here it becomes

Classification assigns one label to a whole image. Detection assigns labels and boxes, and the number of objects is not known in advance — so a detector must propose candidate regions and then decide which ones survive.

Intuition: propose, score, suppress

A sliding-window classifier runs over the image at many positions and scales — correct but wasteful. R-CNN-style two-stage detectors first propose a manageable set of candidate boxes and then classify each one. One-stage detectors (SSD, YOLO) skip proposals: they predict boxes directly from a regular grid, using several grid resolutions so both large and small objects get a suitable scale.

Anchors are fixed reference boxes of various sizes and aspect ratios tiled over the grid. The network predicts offsets from an anchor rather than absolute coordinates, which makes early training easier. Because neighbouring anchors often describe the same object, non-maximum suppression keeps the highest-scoring box and discards overlapping duplicates.

Symbols

\(A,B\): predicted and ground-truth boxes · \(s_i\): box score · \(x,y,w,h\): box centre and size · subscript \(a\): anchor · \(\mathrm{IoU}\): intersection over union · \(\tau\): NMS IoU threshold.

The math

1 · Intersection over union

\[ \mathrm{IoU}(A,B)=\frac{|A\cap B|}{|A\cup B|} \]

Worked with corner format \((x_1,y_1,x_2,y_2)\): \(A=(0,0,4,4)\) (area 16), \(B=(2,2,6,6)\) (area 16). Intersection corners are \((\max(0,2),\max(0,2),\min(4,6),\min(4,6))=(2,2,4,4)\), area \(2\cdot2=4\). Union \(=16+16-4=28\). So \(\mathrm{IoU}=4/28\approx0.1429\). Always state the corner order; \([x,y,w,h]\) needs conversion first.

2 · Non-maximum suppression

Sort boxes by decreasing score, keep the top box, delete every remaining box with \(\mathrm{IoU}>\tau\) to it, and repeat. Worked: scores \(0.9,0.8,0.7\) for boxes 1,2,3 with \(\mathrm{IoU}(1,2)=0.5\), \(\mathrm{IoU}(1,3)=0.1\), \(\tau=0.3\). Keep box 1; box 2 is suppressed (\(0.5>0.3\)); box 3 survives (\(0.1\le0.3\)). Kept indices: \(\{1,3\}\). NMS is normally run per class, since two objects of different classes may overlap.

3 · Precision, recall and AP

\[ P=\frac{TP}{TP+FP}, \qquad R=\frac{TP}{TP+FN} \]

Worked toy set with three ground-truth objects and five ranked detections: outcomes correct, wrong, correct, correct, wrong. Cumulative TP \(=(1,1,2,3,3)\), FP \(=(0,1,1,1,2)\). Precision \(=(1,0.5,0.667,0.75,0.6)\); recall \(=(0.333,0.333,0.667,1,1)\). Four-point interpolation at recall \(0,\frac13,\frac23,1\) takes the maximum precision attainable at or beyond each level: \((1,1,0.75,0.75)\), so \(\mathrm{AP}=2.75/4=\mathbf{0.875}\). mAP averages AP over classes at a stated IoU threshold (e.g. mAP@0.5) — the threshold and averaging rule must always be written down.

4 · Anchor offsets

\[ t_x=\frac{x-x_a}{w_a},\quad t_y=\frac{y-y_a}{h_a},\quad t_w=\log\frac{w}{w_a},\quad t_h=\log\frac{h}{h_a} \]

Worked with a box centre \(x=10\), anchor centre \(x_a=8\), anchor width \(w_a=4\): \(t_x=(10-8)/4=0.5\). If the box width is \(w=6\), \(t_w=\log(6/4)\approx0.405\). The model predicts offsets; adding them back reconstructs the box.

Hands-on labs

Every number below is computed in your browser from the inputs you can change.

Code

import torch
from torchvision.models.detection import fasterrcnn_resnet50_fpn
from torchvision.ops import nms

# Architecture only: weights=None, so nothing is downloaded.
model = fasterrcnn_resnet50_fpn(weights=None, num_classes=91)
model.eval()
print(type(model.backbone).__name__, "FPN backbone",
      model.rpn.head.conv.out_channels, "RPN anchors ->",
      model.roi_heads.box_predictor.cls_score.in_features, "ROI features")

# Synthetic boxes in (x1, y1, x2, y2) corner format
boxes = torch.tensor([[0., 0., 4., 4.], [2., 2., 6., 6.], [10., 10., 14., 14.]])
scores = torch.tensor([0.9, 0.8, 0.7])
keep = nms(boxes, scores, iou_threshold=0.3)
print("kept", keep.tolist())            # tensor([0, 2]) — box 1 overlaps box 0

# Inference shape convention: list of (3, H, W) images in [0,1]

Common mistakes

Wrong corner order

Mixing (x1,y1,x2,y2) with (x,y,w,h) turns a 0.14 IoU into nonsense. Convert explicitly before computing overlap, and assert x2>x1, y2>y1.

Class-agnostic NMS

Suppressing across classes deletes a pedestrian standing in front of a car. Run NMS separately per class (or use class-aware/soft-NMS).

A single-threshold mAP

mAP@0.5 and mAP@[0.5:0.95] are different numbers. State the threshold, the interpolation and whether classes are averaged.

Anchor and stride mismatch

An anchor smaller than the grid stride cannot be assigned well at that scale. Use multiple feature-map scales so anchor sizes match the local stride.

Debug this

A reader runs NMS with iou_threshold=0.05 and reports “all boxes disappeared”. The boxes are valid and scores are between 0 and 1.

Show the likely cause and the fix

The threshold is far too low: almost any pair of boxes for the same object has IoU above 0.05, so the first (highest-scoring) box suppresses everything else. Use 0.3–0.5 as a starting point and inspect the pairwise IoU matrix — the lab prints it. Also confirm NMS is not being run across classes that legitimately overlap.

If even one box is removed when there is only one detection, check that coordinates are corner-form and that no duplicate entry with a higher score was introduced.

Summary

1 · Detection adds localisation to classification; two-stage models propose regions, one-stage models predict on a grid with anchors at several scales.
2 · IoU = |A∩B|/|A∪B| (4/28≈0.143 in the worked example), and NMS greedily keeps the highest score while suppressing boxes above a threshold.
3 · AP is the precision–recall summary at a stated IoU threshold (0.875 in the toy calculation); mAP averages AP over classes — always state the rule.

Cheat sheet — M1·07

  • \(\mathrm{IoU}=|A\cap B|/|A\cup B|\); corner format \((x_1,y_1,x_2,y_2)\).
  • Worked: A=(0,0,4,4), B=(2,2,6,6) → 4/28 ≈ 0.143.
  • NMS: sort by score → keep top → remove IoU > τ → repeat; per class.
  • Precision \(TP/(TP+FP)\), recall \(TP/(TP+FN)\).
  • Anchor offsets: \(t_x=(x-x_a)/w_a,\; t_w=\log(w/w_a)\).
  • mAP requires a stated IoU threshold and class-averaging rule.
