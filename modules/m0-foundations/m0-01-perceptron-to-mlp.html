From perceptron to multilayer networks

— · Lesson 1 of 5 · Exact math labs

One neuron draws a straight line. Stack two layers and the line becomes a shape — this lesson shows exactly where that extra power comes from, with arithmetic you can check.

Objectives

  • Show, with numbers, that no single linear unit can compute XOR.
  • Build a 2→2→1 ReLU network by hand that outputs 0,1,1,0.
  • Explain what the universal approximation theorem promises — and what it does not.
  • Count parameters and predict the effect of removing the nonlinearity.

You know this from ML → here it becomes

Logistic regression is a single neuron: a weighted sum followed by a sigmoid, trained with cross-entropy. Nothing changes in that sentence except that we now stack many of them and choose other squashing functions. The new ingredient is the hidden layer, which lets the model bend its decision boundary.

Intuition: a neuron is a line, a layer is a shape

A single unit computes \( z = w_1x_1 + w_2x_2 + b \), then squashes \(z\) through a nonlinearity. Ignoring the squash, the surface where the output flips sign is \( w_1x_1 + w_2x_2 + b = 0 \) — a straight line. So whatever the weights, one neuron can only split the plane in two halves.

XOR is the classic counter-example. Label the corners of the unit square: \((0,0)\) and \((1,1)\) are class 0; \((0,1)\) and \((1,0)\) are class 1. The two classes sit on diagonally opposite corners, so every straight line that separates one pair puts the other pair on the same side. Drag the sliders below and watch the accuracy readout refuse to reach 4/4.

The background is the sigmoid of the pre-activation, so it fades smoothly from surface to accent. The black line is the exact boundary \(z=0\). A single line can cut off at most one corner of the square, so one of the four points is always on the wrong side: 3/4 is the ceiling and the readout shows it.

Depth, not width, is what turns lines into polygons. Each hidden unit contributes one straight cut; their ReLU combination glues half-planes into a piecewise-linear region.

The math

1 · One layer is an affine map

For a column vector of inputs \(x\in\mathbb{R}^{n_{in}}\):

\[ z = Wx + b, \qquad W \in \mathbb{R}^{n_{out}\times n_{in}},\; b\in\mathbb{R}^{n_{out}} \] \[ a = \phi(z) \]

\(W\) has one row per output unit; row \(i\) holds that unit's weights. A 2→4 layer therefore holds \(2\cdot4 = 8\) weights and \(4\) biases: 12 numbers.

2 · Stacking composes the maps

\[ f(x) = W_2\,\phi\!\left(W_1x + b_1\right) + b_2 \]

Without \(\phi\) this collapses: \(W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2)\), which is just another affine map. The nonlinearity is the entire source of extra capacity. That single fact explains most “my network behaves like a linear model” bugs.

3 · XOR by hand

Take two ReLU hidden units and the inputs in \(\{0,1\}^2\). Choose

\[ h_1 = \mathrm{ReLU}(x_1 + x_2), \qquad h_2 = \mathrm{ReLU}(x_1 + x_2 - 1), \qquad y = h_1 - 2h_2 \]

Every row matches. Written as matrices with \(s = x_1+x_2\): \(W_1 = \begin{bmatrix}1&1\\1&1\end{bmatrix}\), \(b_1 = \begin{bmatrix}0\\-1\end{bmatrix}\), \(W_2 = \begin{bmatrix}1&-2\end{bmatrix}\), \(b_2 = 0\). Note that \(y > 0.5\) exactly when \(0.5 < s < 1.5\) — a band, not a half-plane. Two ReLUs bought us a stripe.

Parameter count for this 2→2→1 network:

\[ \underbrace{(2\cdot 2 + 2)}_{6} + \underbrace{(2\cdot 1 + 1)}_{3} = 9 \]

4 · Choosing the nonlinearity

The derivative is what backpropagation multiplies through, so the shape of \(\phi'\) matters more than the shape of \(\phi\). ReLU has derivative exactly 0 or 1; sigmoid and tanh squeeze it below 1 and shrink gradients with depth; GELU and swish are smooth compromises used in transformers.

Watch ReLU at \(x=0\): the function is continuous but the derivative jumps from 0 to 1. Our implementation returns 0 there, which is the usual convention — it does not matter in practice because the probability of landing exactly on 0 is nil.

5 · Universal approximation, stated carefully

A network with a single hidden layer and enough units can approximate any continuous function on a compact set to arbitrary accuracy (Cybenko 1989; Hornik 1991). Formally, for every \(\varepsilon>0\) there exist \(N\) and weights such that \(\sup_{x\in K}\lVert f(x)-g(x)\rVert<\varepsilon\).

Read the quantifiers in order, because they are the whole story:

  • “there exist weights” — the theorem says nothing about whether gradient descent finds them.
  • “enough units” — \(N\) may be astronomically large; it is not a recipe.
  • “continuous on a compact set” — no promise outside the region you trained on.

In practice depth beats width: a deep ReLU network represents the same function with far fewer parameters than a shallow one. That is the empirical reason the rest of this course is about architecture, not about ever-wider single layers.

Code

The hand-built network above, trained from scratch in PyTorch. The only subtlety is the loss: for a binary output with logits, use BCEWithLogitsLoss, which fuses the sigmoid and the log for numerical stability. 

import torch
from torch import nn

torch.manual_seed(0)

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])

model = nn.Sequential(
    nn.Linear(2, 4),   # 2*4 + 4 = 12 parameters
    nn.ReLU(),
    nn.Linear(4, 1),   # 4*1 + 1 = 5 parameters
)
loss_fn = nn.BCEWithLogitsLoss()
opt = torch.optim.Adam(model.parameters(), lr=0.05)

for step in range(500):
    opt.zero_grad()                 # gradients accumulate otherwise
    logits = model(X)               # shape (4, 1), no sigmoid here
    loss = loss_fn(logits, y)       # sigmoid + BCE fused
    loss.backward()
    opt.step()

with torch.no_grad():
    p = torch.sigmoid(model(X)).squeeze(1)
    pred = (p > 0.5).long()

print(f"loss {loss.item():.4f}")
print("probabilities", [round(v, 4) for v in p.tolist()])
print("predictions  ", pred.tolist())   # [0, 1, 1, 0]
print("parameters   ", sum(q.numel() for q in model.parameters()))  # 17
import tensorflow as tf

tf.random.set_seed(0)

X = tf.constant([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = tf.constant([[0.], [1.], [1.], [0.]])

model = tf.keras.Sequential([
    tf.keras.layers.Dense(4, activation="relu", input_shape=(2,)),
    tf.keras.layers.Dense(1),          # logits: no activation
])
model.compile(
    optimizer=tf.keras.optimizers.Adam(0.05),
    loss=tf.keras.losses.BinaryCrossentropy(from_logits=True),
    metrics=["accuracy"],
)
model.fit(X, y, epochs=200, verbose=0)

probs = tf.sigmoid(model(X)).numpy().ravel()
print((probs > 0.5).astype(int))        # [0 1 1 0]
print(model.count_params())              # 17

Two runs will not print identical digits: Adam starts from random weights. Both should reach four correct predictions within a few hundred steps on this toy problem.

Common mistakes

No nonlinearity

Linear → Linear → Linear is one matrix. Training loss falls, accuracy stalls at whatever the linear model can do. If your deep net matches logistic regression exactly, check the activation first.

Sigmoid twice

Pairing sigmoid in the model with BCEWithLogitsLoss computes σ twice and saturates. Either output logits and use the fused loss, or output probabilities and use plain BCELoss — never both.

Forgetting zero_grad()

PyTorch adds new gradients to the existing .grad buffers. Skip the reset and the effective step size grows every iteration until the loss explodes.

Blaming the optimizer

On a 17-parameter toy problem, Adam, SGD with momentum, and plain SGD all solve XOR. If one of them does not, the bug is in the data, the loss, or the shapes.

Debug this

A reader reports: “my 2→4→1 network stays at exactly 50% accuracy on XOR and the loss barely moves.” The code is the PyTorch listing above with one line changed.

Show the likely cause and the fix

The activation was dropped — either deleted, or replaced by nn.Identity(). Two stacked linear layers are still linear, so the model can only place one straight boundary, and XOR is symmetric enough that a straight boundary through the middle gets exactly 2 of 4 points right no matter where it sits. Restore nn.ReLU() between the layers and the loss will start moving within a few dozen steps.

Second most likely: labels are shape (4,) while logits are (4, 1), and broadcasting silently trains on the wrong pairs. Print both shapes before blaming the optimizer.

Summary

1 · A neuron computes an affine map plus a nonlinearity; its boundary is one hyperplane.
2 · A hidden layer composes many hyperplanes; ReLU glues them into piecewise-linear regions, which is how XOR becomes representable with 9 parameters.
3 · Universal approximation promises existence, not learnability — depth buys the same functions with fewer parameters.

Cheat sheet — M0·01

  • \(z = Wx+b\), \(a=\phi(z)\); parameters of a layer: \(n_{in}n_{out}+n_{out}\).
  • Without \(\phi\): \(W_2(W_1x+b_1)+b_2\) collapses to one affine map.
  • XOR: \(h_1=\mathrm{ReLU}(x_1+x_2)\), \(h_2=\mathrm{ReLU}(x_1+x_2-1)\), \(y=h_1-2h_2\).
  • 2→4→1 MLP: 17 parameters. 2→2→1: 9.
  • Logits in, BCEWithLogitsLoss out — never sigmoid twice.
  • \(\mathrm{ReLU}'(0)=0\) by convention; sigmoid′ ≤ 0.25, tanh′ ≤ 1.
